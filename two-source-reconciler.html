Two-source reconciler

A dependency-free deterministic comparison primitive for two closed datasets keyed by one stable identifier and an explicit list of safe-integer fields.

  • Sorted output keys make classification independent of input row ordering.
  • Missing-left, missing-right, duplicate-key, and per-field mismatch states remain explicit.
  • The core has no network adapter and no mutation adapter.
  • Aggregate left, right, and delta totals are returned for every declared field.

Input contract

{
  "fields": ["a", "b", "c"],
  "left":  [{"rowId":"L1","key":"K1","values":{"a":100,"b":10,"c":90}}],
  "right": [{"rowId":"R1","key":"K1","values":{"a":100,"b":10,"c":90}}]
}
