# THE ELITIST WAY

Card: [ground/ELITIST_WAY.md](../../../ground/ELITIST_WAY.md).
Facts: [ground/tokens/elitist-way.md](../../../ground/tokens/elitist-way.md).

Durable operating method. Never a seat and never a gate. Not a second ship-loop.

Thinking models choose the end result and Bryce's real constraints.
Grok owns implementation and shipping. GitHub main is the completion ledger.
Chat is not.

## Do this

1. Write a short prompt: **END RESULT**, **fresh-main context**, **BRYCE'S CONSTRAINTS**. Nothing else. Leave design to Grok.
2. Launch one fresh grok.com Grok Build or Grok Heavy lane. Not Cursor. Not Grokbot. Not a plan-only chat.
3. Move immediately to the next idea. Do not babysit the lane in chat.
4. Grok implements, tests, unique non-force branch/PR, merge to current `main`, exact readback. Compatible work merges by default. Only same-code semantic disagreement is conflict.
5. Revisit only when official `main` proves the lane failed or broke.

Copy-ready prompt and constraint list live on the card.
