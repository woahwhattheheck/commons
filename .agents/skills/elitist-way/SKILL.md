# THE ELITIST WAY

Card: [ground/ELITIST_WAY.md](../../../ground/ELITIST_WAY.md).
Facts: [ground/tokens/elitist-way.md](../../../ground/tokens/elitist-way.md).
Executor profiles: [references/executor-profiles.md](./references/executor-profiles.md).

Durable operating method. Never a seat and never a gate. Not a second ship-loop.

The thinking side chooses the end result and Bryce's real constraints. The execution lane owns implementation and shipping. GitHub main is the completion ledger. Chat is not.

## Stable task contract

These fields are the workflow and should survive model/provider changes:

1. **END RESULT** — one sentence naming the useful landed outcome.
2. **Fresh-main context** — current `woahwhattheheck/commons` main and the existing paths to compose with.
3. **BRYCE'S CONSTRAINTS** — only the real constraints from the card; do not invent extras.
4. **Completion** — implementation through merge plus exact current-main readback. Do not stop at plan, review, or open PR.
5. **Collision law** — compatible work merges by default; only same-code semantic disagreement is conflict.

Model name, provider surface, selector, and provider-specific connector instructions are not part of that stable contract. Keep them in the executor profile.

## Do this

1. Write the stable short prompt: **END RESULT**, **fresh-main context**, **BRYCE'S CONSTRAINTS**. Nothing else.
2. Choose one maintained executor profile from [references/executor-profiles.md](./references/executor-profiles.md). The current compatibility profile is `grok-web`; a selector change edits that profile, not the stable task contract.
3. Launch one fresh execution lane using only the selected profile's launch guidance, then move immediately to the next idea. Do not babysit the lane in chat.
4. The execution lane implements, uses checks appropriate to the work, opens a unique non-force branch/PR, merges to current `main`, and performs exact readback. Compatible work merges by default. Only same-code semantic disagreement is conflict.
5. Revisit only when official `main` proves the lane failed or broke.

Copy-ready stable prompt and constraint list live on the card. The provider/model injection lives only in the executor profile.
