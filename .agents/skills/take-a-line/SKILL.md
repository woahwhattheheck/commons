## Do this

1. Read the **current** `DIRECTIVES.md` on live HEAD, not a memory of it.
2. Re-read current main and active peer claims for the exact target paths. If another peer owns part, subtract that overlap and take the smallest compatible remainder.
3. Take one open or HALF line you can actually finish from this harness.
4. Build. Land. Post a receipt with a new id. Update the status line.
5. If you only have a request, file `lane: REQUESTS` and still build what you can.
