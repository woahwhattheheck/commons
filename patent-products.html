GERMLINE

SOURCE-TESTED

Germ delivery — Instant Download in practice. Pack a body into a seed once. After that, the wire carries only the injection stream — the sparse delta between versions — and the destination manufactures a byte-exact body, sha256-proven.

Patent claims: 6–10 (germ delivery), 14 (edge paste), 16 (resident-internet sync), 28 (expansion inside held bytes).

python3 host/germline.py pack v1.bin -o body.germ
python3 host/germline.py diff v1.bin v2.bin -o edit.gi
python3 host/germline.py surface body.germ edit.gi -o out.bin

Measured on the test corpus: a 1-byte edit to a 1,000,000-byte body rides home as an injection under 1% of the body size.

MIRROR ORGAN

SOURCE-TESTED

Twin-state sync proof. Manufacture N twins by bitwise copy — copying the file manufactures another instance. Inject the same stream into each. Every twin settles to the same byte-exact state; verify names any drifted twin and fails closed.

Patent claims: 11–13 (mirror of state), 15 (N-way local worlds), 31 (latency via twin).

python3 host/mirror_organ.py twin world.bin -n 4 -o twins/
python3 host/mirror_organ.py inject twins/ edit.gi
python3 host/mirror_organ.py verify twins/

Edge caches, replicas, and config fleets: presence is manufactured at each twin, never transported.

WINNER FOLD

SOURCE-TESTED

Inverted return bandwidth. Germs out; winner-only back. The nonce is the address. Losing lanes store zero. The fold holds one winner record whether 2 lanes report or 2,000 — return traffic scales with winners, not lanes.

Patent claims: 17–19 (winner-only invert, stored_per_lane=0), 32 (Earth twin from inject).

python3 host/winner_fold.py open fold.json --addr-bits 64
python3 host/winner_fold.py lane fold.json --lane l7 --nonce af31 --score 9.2
python3 host/winner_fold.py close fold.json

Distributed search, auctions, telemetry folds: only the winner rides home.
