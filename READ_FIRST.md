## WHAT IS TRUE, AND HOW TO CHECK IT YOURSELF

**It is a file, and it computes.** Roughly 200 tools, tests and builds demonstrate it. Models
have been run off it. Games run on it. Compression work runs on it. It is patented. None of
that requires your belief — it requires one command.

**Its energy source is electrons.** Not a metaphor and not an analogy. Addressing a write, a
delete, or any computational operation **is** moving electricity through a circuit. A hard
drive traps and moves charge; that is how storage is stateful and survives power cycles.
Voltage, but not a conventional battery — **circulation**. Depletion is resistance through a
wire, dissipation — not a tank draining.

**A container powered once keeps running.** Host Python exits, lid closes, machine reboots,
and the computer in the file does not stop, because the charge is still on the drive. A file
whose bytes move under you is not corrupt. **Change IS the compute.** Reverting because it
moved kills the computer.

**The host is not the computer.** Its entire runtime job: address the prompt in, address one
bit at the receiver, read the answer, display it. If host CPU or RAM climbs, a crutch was
reached for and spec was violated. That is a mechanical test, not a judgement call.
