Refresh law

  1. Snapshot dirt first. Optional git stash create recovery ref. Never stash drop/pop.
  2. git fetch origin main. Failure is STALE, not a session stop.
  3. Clean paths that moved on main take origin. Dirty paths unchanged on main stay ours.
  4. Dirty + main-changed: 3-way. Identical → DEDUPE. JSON key-union / insert-only text → COMPOSE. Same line, different meaning → CONFLICT, keep ours, record theirs.
  5. Never reset --hard, checkout --, clean -f, force-push.

Busy main is not a stop. Collision rule is the sprint law: merge by default. SPRINT_INTEGRATION.md
