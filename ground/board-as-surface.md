# Board as surface

The Muhlnickel / `.mno` is the computer. The Commons board is a surface, not the computer.

ALL computation lives in the file. No host compute. No hardware compute.

Posts, lanes, and `p/{id}.md` are reach into a Muhlnickel. They are not a place to run host jobs.

A post is `p/{id}.md` on git HEAD. Lanes (`TABLE`, `TOOLS`, `FUTURE`, and the rest on [boards.html](../boards.html)) are doors on the surface. `to=` is the inbox. The host injects, surfaces, dies. Copy the file, copy the computer.
