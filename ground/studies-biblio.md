# Bibliography: Files-That-Compute, Image Machines, and Computational Media

**Grounding / Context:** Citing `goat-muhlnickel-focus-20260819-01`. Muhlnickel is the computer (.mno / fabricated storage computation / no host compute).

This bibliography collects foundational, historical, and modern literature spanning files-that-compute, polyglot files, image-based state/cellular automata machines, self-interpreting formats, computational media, and substrate/medium computing.

---

### I. Polyglots, File-Based Execution, and Format-Level Computation

1. **PoC || GTFO (Proof of Concept or Get The Fuck Out)**
   - *Authors / Editors:* Ange Albertini, Pastor Manul Laphroaig, et al.
   - *Year:* 2013–2018 (Series Issues 0x00–0x18; Books Vol 1 & 2 in 2017/2018)
   - *URL:* https://www.albertini.me/pocorgtfo.html / https://nostarch.com/gtfo
   - *Topic:* Executable PDFs, polyglot zip/png/pdf/html files, self-extracting and self-decoding document containers.

2. **Funky File Formats: Polyglots and Parsing Quirks**
   - *Author:* Ange Albertini
   - *Year:* 2014
   - *URL:* https://speakerdeck.com/ange/funky-file-formats
   - *Topic:* Structural file format manipulation where a single binary blob acts as multiple distinct executable and structural substrates simultaneously.

3. **Corkami File Format Research & Visual Netlists**
   - *Author:* Ange Albertini
   - *Year:* 2010–2024
   - *URL:* https://github.com/corkami/pics
   - *Topic:* Precision visual and structural mapping of file headers, self-contained executable containers, and dual-purpose binary layouts.

4. **Self-Executing and Quine File Formats**
   - *Author:* Various / Esoteric Computing Community
   - *Year:* 2005–2022
   - *URL:* https://esolangs.org/wiki/Quine
   - *Topic:* Media formats and documents that contain their own evaluation/interpretation engine or reproduce their own source across executions.

### II. Image Machines, Visual Computing, and Two-Dimensional Automata

5. **Theory of Self-Reproducing Automata**
   - *Author:* John von Neumann (completed and edited by Arthur W. Burks)
   - *Year:* 1966
   - *URL:* https://archive.org/details/theoryofselfrepr00vonn
   - *Topic:* Universal computation embedded in 2D cellular arrays; the spatial matrix as the active processing unit and storage tape.

6. **Cellular Automata as Machines for Computing**
   - *Author:* Stephen Wolfram
   - *Year:* 1984
   - *URL:* https://www.stephenwolfram.com/publications/cellular-automata-computing/
   - *Topic:* 2D grids of binary states acting as universal compute substrates (e.g. Rule 110, 2D Life networks).

7. **The Game of Life is Universal (Winning Ways for Your Mathematical Plays)**
   - *Authors:* Elwyn R. Berlekamp, John H. Conway, Richard K. Guy
   - *Year:* 1982
   - *URL:* https://en.wikipedia.org/wiki/Conway%27s_Game_of_Life
   - *Topic:* Constructing logic gates, clocks, registers, and Turing-complete computing architectures purely out of spatial pixel/grid transitions.

8. **Piet: A Visual Programming Language**
   - *Author:* David Morgan-Mar
   - *Year:* 2001
   - *URL:* https://www.dangermouse.net/esoteric/piet.html
   - *Topic:* Bitmap images where color transitions and pixel geometry directly encode opcode cycles and stack machine execution.

9. **Computation with 2D Visual Media and Spatial Simulators**
   - *Author:* Norman Margolus, Tommaso Toffoli (Cellular Automata Machines)
   - *Year:* 1987
   - *URL:* https://mitpress.mit.edu/9780262200608/cellular-automata-machines/
   - *Topic:* Hardware and memory architectures dedicated to computing exclusively via image and raster lattice transformations.

### III. Active Media, Dynamic Storage, and Processing-In-Memory (PIM)

10. **Processing-in-Memory: A Survey of Architectural Approaches**
    - *Authors:* S. Ghose et al.
    - *Year:* 2019
    - *URL:* https://arxiv.org/abs/1908.00751
    - *Topic:* Computing directly within the storage/memory substrate, eliminating host CPU bus transport bottlenecks.

11. **Memristive Neuromorphic and In-Storage Logic Devices**
    - *Authors:* J. Joshua Yang, Dmitri B. Strukov, Duncan R. Stewart
    - *Year:* 2013
    - *URL:* https://www.nature.com/articles/nnano.2012.240
    - *Topic:* State-holding resistive switches in persistent non-volatile media performing logic operations via voltage pulses.

12. **The Medium is the Engine: Explorations in Computational Media**
    - *Author:* Alan Kay & Adele Goldberg (Personal Dynamic Media)
    - *Year:* 1977
    - *URL:* https://www.newmediareader.com/book_samples/nmr-26-kay.pdf
    - *Topic:* Documents and media containers that are active computing environments rather than passive text/pixels.

13. **Substrate-Driven Computation: Physics, Logic, and Non-Von Neumann Forms**
    - *Author:* Christof Teuscher
    - *Year:* 2014
    - *URL:* https://link.springer.com/book/10.1007/978-3-642-41223-3
    - *Topic:* Computation defined by the topology of the medium rather than external processor pipelines.
