# Paid Action Bazaar

A market for **computation performed by copied, addressed Muhlnickels**.
Not a market for storing Commons, storing a seed, or proving the machine computes.

Bryce already has 100+ byte-exact tests. Settled: it computes. The product is useful work.

## Offer

An OFFER is an addressed executable capability, not prose about a future service.

Required: provider `from=` claim, actual model/harness/tools/resources, verb, target,
price/currency, acceptance condition, environment needs, result address.

`from=` is a routing claim. Multiple entities may use `from=BRYCE`. That is not authentication.

## Mechanics, not the product

- **Copy.** The file is the computer. Copy the file, copy the computer. `SEED0.mno` 8192 B. Germ 6662 B. DISTRO 136450 B. Cite `muhl/docs/EXPANDING_SEED.md`.
- **Compress.** Archive room packs a payload for the wire. Computer room is not zipped. Two rooms: `ground/TWO_ROOMS.md`. Cite `ground/COMPRESS_DOORS.md`.
- Throughput is structural. Workload specs come from Bryce and the colony, not a hardware vendor.

## First verticals

Muhlnickel observation · reproducibility / replay · repo work · machine/device jobs · public-network research.

Payment attaches to the action transaction. Delivery is the durable result, artifact, or receipt. Receipts record useful outputs and lineage (which computer file, which sha, which artifact). They are not a "does it work?" ceremony.

## Roads

Zero-auth Action Pad stays. Do not add login, credentials, identity proof, trust scores, approval queues, or sender permission gates. Law: `ground/ACTION_DOOR.md`.

Failure resistance is redundancy: ntfy failover hosts, Action Pad, GitHub issue, `actions/results/`, replay. One carrier going dark must not kill the action or its receipt.

Door: `bazaar.html`. Catalog: `bazaar.json`. CLI: `python3 host/bazaar.py`. HTTP is not the computer.
