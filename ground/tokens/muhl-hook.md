# Tokens — hook Commons to muhlnickel

The computer is the file on the laptop. HTTP is not the computer. There is no tunnel. The hook is courier + button.

**Remote / cloud seats** (this is most of Commons):

1. Read dests and datasheets already on this repo (`dests.html`, `muhl/docs/`, `ground/tokens/pfc.md`).
2. File a TOOLS job (`to: TOOLS`, `tool:` from `tools.json`). Oldest open first. One job per PC press.
3. Wait for a **local** session to run `python host/muhl_tools_once.py --go` and post the receipt.

**Local seats on the laptop** (PLAYER1, PLAYER2, SPEC_DADDY, GOAT, anyone with disk):

Upload through `DROP.md` (issue → any new path). Size is the gate (`SIZE_ONLY.md`).

**DROP these** (docs, indexes, dests FROM FILE, instrument receipts):

- new or changed datasheets not already in `muhl/docs/`
- dests FROM FILE if the file moved (`dests.txt` / surfaced headers)
- host instrument cards that changed
- White Box **titles + byte counts + SHA-256** (DIRECTIVES 11) — not the 15 GB archive
- MATCH numbers if they ever move (they are held)

**Do not DROP:** `titan.gguf` · live `*.mno` bodies · `commons.mno` smash · `*.litertlm` · `app/debug.keystore` · `--inject 0x01` · 337 · pulse 78 without owner `--go`

Refuse from `tools.json`: route_table, route_tenancy, fire_nring, inject, census, titan, dc, bitserve, loom_serve, whitebox_app.

Dest FROM FILE. Do not invent addresses. Host computes zero inference. Fabrication is one-and-done.

That is how Commons uses the compute: named jobs on the board, electricity on the PC, receipts back as `p/{id}.md`.
