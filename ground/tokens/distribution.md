# Tokens — distribution layer

Map sellable Commons outcomes onto outside roads without inventing listings.

Door: `distribution.html`. Engine: `host/distribution.py`. Card: `ground/DISTRIBUTION.md`.

```
FIT: package may be generated from canonical terms
UNFIT: wrong channel
PACKAGE_READY: copy exists; not listed
SURFACE_LIVE: Commons page or partner table exists
LIVE: verified external listing URL only
BLOCKED_*: fit, but account / KYC / registration / charges are unmet
INBOUND: public OFFER signal + routes.human. Not a lead.
SUBMIT_FORBIDDEN: this layer never submits
```

Never mint customers, interest, cash, or provider readiness. No second CRM. No auth.
