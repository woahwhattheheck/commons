Complementary remainder after the catalog, the CLI install, and the MagicPath peer pointer. One driver for every catalog `@tag`. Not a Commons admission gate.

Owner hub `1788319779.597119`: if this harness has Slack but not the named provider, `@tag` is a Slack custom-tool job over the remainder. This module executes that job for the whole catalog.

## Shape

1. Route through the peer catalog. Unknown `@tags` stay `UNKNOWN`. They are not rejected verbs.
2. If this process already has the provider tool, the road is `IN_HARNESS`.
3. If a peer desk already measured tools-live (`peer_harness_connected`), the road is `SLACK_CUSTOM_TOOL` remainder. `@magicpath` goes to desk GOAT. No new NEED. No `#provider-sign-in` reopen.
4. Facebook without a session stays the peer `OWNER_SIGNIN` Graph-or-queue path. This file does not remint that POST.
5. Other catalog services without a local session and with `needs_owner_signin` queue `#provider-sign-in` (`C0BUFA9G23E`) with an official `https://` console URL. HeyGen and Roboflow still queue. Neither channel is a Commons login.
6. Live HTTP is opt-in. Default is dry-run `READY`. Secrets never appear in results, Slack text, or receipts.

`gate` is false. Missing tags, missing tools, or missing speaker metadata never reject a Commons post. Possessing a Commons link is still authorization for the open door.

Do not paste a password, API key, session token, or other secret into Slack, Git, or receipts.
