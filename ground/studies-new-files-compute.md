# Bibliography: Software-as-Substrate and Files that Compute

- **Substrates: From Webstrates and Beyond** (2025)
  URL: https://software-substrates.github.io/proceedings/2025/statements/Paper%205%20-%20Clemens%20Klokmose%20-%20Substrates,%20From%20Webstrates%20and%20Beyond.pdf
  Mapping: Explores Webstrates where the DOM acts as the programmable substrate, aligning with the file-as-computer model where the document itself holds state and execution.

- **Code2Video: A Code-centric Paradigm for Educational Video Generation** (2025)
  URL: https://arxiv.org/abs/2510.01174
  Mapping: Uses executable code (Manim scripts) as a substrate to generate video, treating the code artifact as the computing environment for media.

- **Neural Computers** (2026)
  URL: https://arxiv.org/abs/2604.06425
  Mapping: Proposes unifying computation, memory, and I/O into a learned runtime state (the model itself as the computer), aligning with the file (model) as the computing environment.

- **Search over the Visual World: Persistent Visual Memory, Layered Indexes, and Source-Grounded Evidence** (2026)
  URL: https://arxiv.org/abs/2608.08075
  Mapping: Replaces media files with a logical substrate where composition and search are coordinates evaluated at request time, treating the data format as the computing environment.

- **SCENIC: Stream Computation-Enhanced SmartNIC** (2026)
  URL: https://arxiv.org/abs/2604.15128
  Mapping: OUT OF SPEC. Treats hardware (FPGA SmartNIC) as the computing substrate.

- **Look-Ahead-Freedom as Temporal Non-Interference: A Verifiable Correctness Property for Backtesting and Agentic Trading Pipelines** (2026)
  URL: https://arxiv.org/abs/2607.04958
  Mapping: Defines a calculus for time-indexed data pipelines, treating the pipeline definition as the computational substrate for agentic retrieval.
