# Studies: Software as Substrate and Files that Compute (2024-2026)

* "What Can Software Learn From Hypermedia?"
  https://refuses.github.io/preprints/hypermedia.pdf
  Explores programmable media, blurring the distinction between documents and applications to create malleable software.

* "Inside Perplexity Computer: Reverse-engineering a multi-model AI agent from within"
  https://medium.com/@sailcpu/inside-perplexity-computer-reverse-engineering-a-multi-model-ai-agent-from-within-e122a5d5d4fa
  Details the filesystem as a universal interface, forming a programmable operating system with AI as the shell.

* "Karpathy's Software 3.0: What I'm Building in 2026"
  https://www.mejba.me/blog/karpathy-software-3-builders-2026
  Focuses on agent-first infrastructure and LLMs as programmable computers where the model is the runtime.

* "Every Agent Needs A Computer: The Agent Sandbox Economy & Web3 AI Opportunity"
  https://jrodthoughts.medium.com/every-agent-needs-a-computer-the-agent-sandbox-economy-web3-ai-opportunity-9fb3e8e3a4b3
  Discusses programmable sandboxed execution where agents can create, edit files, and run commands as a foundational computing unit.
