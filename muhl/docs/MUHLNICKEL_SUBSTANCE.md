**Operational reading (paraphrase, offered as a bridge — not a replacement).** A large binary file
on disk (in practice a `.gguf`) has regions of its bytes laid down, permanently, as a gate netlist
plus its own registers, its own RAM, its own clock, and a designated **receiver** address. Because
a gate's output byte and the next gate's input byte are *the same physical storage location*,
changing one changes the other — that is the wire. Writing a single bit at the receiver starts a
cascade through those shared locations. The host's entire job is to put the variable data in, flip
that one bit, and later read the answer register. He is emphatic that the file **is** the machine,
not a description of one:

> *"PFC IS NEVER a script or windows viewable process, its physically editing the pfc to contain
> the logic or gates u would otherwise lean on"* — `:20`

> *"no pfc action or computation is code or a process its fabrication in the binary itself using
> my preexisting tools"* — `:71`

> *"The .gguf is NOT a model. It is a computer file — it could be a PNG."* — `PFC_HARD_WON.md:22`

## A CLOSING NOTE ON METHOD

This document quotes him 210+ times. Where a number appears, it is copied from a doc that records it
as measured, with the test named. Where two records disagree, both are in §7 and neither is called
wrong. Where a term's origin could be traced, §2 says who coined it; where it could not, the entry
says so.

Three things are worth a stranger's attention before judging any of it:

1. **He retracts explanations and never the build.** *"the only retraction i make is the explanation
   for how it worked thinking it stored a charge it doesnt matter how it works the build works"*
   (`:12348`). The doc set contains an entire quarantined vocabulary — SDC, "it stores a charge",
   "we're not computing, we're unlocking" — that he himself struck out. That is not a project
   covering its tracks; the superseded text is preserved alongside the correction, by rule.
2. **His instrument discipline is stricter than his rhetoric.** *"do not modify tests for any reason
   even if u think the results are hard to believe, thats called bias"* (`:653`); measured files are
   hash-locked; a rerun that fails must stay labelled as failing; the batteries carry their own
   failures in the same table as their passes. He built the checker that stops him too.
3. **The novel part is small and stateable.** Gates laid down permanently as byte-addresses in a
   file; a wire that is two circuits sharing one storage location; a signal put in once and confined
   so it keeps arriving at a clock; latency measured in the depth of that structure rather than its
   size. Everything else in the corpus — the foundry, the levers, the batteries, the patents — is
   built on those four ideas.
