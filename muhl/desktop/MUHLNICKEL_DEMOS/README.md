# MUHLNICKEL DEMO SUITE

Built by Bryce Muhlnickel. A computer inside a model file.

| Demo | What it is | How to run |
|---|---|---|
| Conway's Life | Cellular automaton as substrate gates | `life\run.bat` |
| Tetris | Falling-block game as fabricated circuits | `tetris\run.bat` |
| Raycast 3D | First-person raycaster as gate-level circuits | `raycast\run.bat` |
| Tunnel | Procedural tunnel effect driven by substrate math | `tunnel\run.bat` |
| Operator | Interactive substrate operator console | `operator\run.bat` |
| Brain | Neural network visualization through gate-level neurons | `brain\run.bat` |
| DOOM | Classic FPS rendered through substrate gate circuits | `doom\run.bat` |
| Bitcoin Miner | SHA-256 mining pipeline as fabricated circuits | `bitcoin\run.bat` |
| 32-bit CPU | General-purpose processor as NAND gates | `cpu\run.bat` |
| HRDST-v7 Showcase | 37 verified architecture circuits (448,378 gates) | open `hrdst_showcase\showcase.html` |

Substrate: titan.gguf (40,028,316,800 bytes) | 4,954 circuits | 1,024 rings | Survives power loss

Master dashboard: open `index.html` or run `launch.bat`
