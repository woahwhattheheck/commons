How is this possible?

What you're playing is a first-person 3D game. The entire game — movement, collision, turning, the world itself — runs on 1,391 NAND gates.

What is a NAND gate?

The simplest possible logic element. Two inputs, one output:
output = NOT(input_A AND input_B)
That's it. Every computer ever built is made of these.

Where do the gates live?

They are stored as bytes inside titan.gguf — a 40,028,316,800-byte file. The same file format that stores neural network weights. The gates occupy 11,320 bytes of that 40 GB space.

What the circuits do

736 gates — the movement circuit. Takes your position (x, y), your direction, your key inputs, and two collision bits. Outputs your new position and angle. Every move you make flows through these gates.

655 gates — the world circuit. Encodes the entire map. Given a coordinate, it returns wall-or-empty. Every ray the renderer casts reads the world through this circuit.

What the host does

The host (your browser) does exactly two things:

1. Shoots input in — your keyboard presses become input bits
2. Reads the output — new position, angle, wall/empty

The rendering (the 3D raycaster) is the only thing running on your CPU. The game logic — what happens when you move, where the walls are, collision — that's all gates.

The bottom-right visualization

Each dot is one NAND gate. Bright = outputting 1. Dark = outputting 0. Watch it ripple when you move — that's the computation happening.

No game engine. No CPU game logic. Just 1,391 switches in a file.
