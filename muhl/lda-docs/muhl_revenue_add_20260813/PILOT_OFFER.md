# Paid NDA pilot

**Inventor:** Bryce Muhlnickel  
**Date:** 2026-08-13  
**Offer:** a paid, time-boxed look. Not a repo. Not a dump.

## What the buyer pays for

A closed-room pilot of two facts that already sit on the inventor's machine:

1. **White Box sighted-edit.** Read and change *meaning* in a parameter file from the bits, with no inference. Alignment is sighted, reversible, and measured — not a blind fine-tune.
2. **Inject / surface proof.** The same class of file is a computer. The host writes a bounded inject (prompt / start signal) and reads a bounded surface (answer register / safezone). The file computes. There is no host forward pass.

Buyer is a lab, fund, or company drowning in blind fine-tunes and GPU bills. They pay to sit with the instrument for a week under NDA. They leave with a written finding they can take internally. They do not leave with the factory.

## Show vs secret

**SHOW (in the room, under NDA):**

- White Box: decompile a token, move a concept on a measured axis, revert byte-exact.
- Sign-geometry that is already on the machine (true/false sitting on top of each other).
- Inject / surface on one named organ that already exists in the registry.
- Power-cycle fact: the computer is the file; killing the host process does not kill a process that was never the computer.
- One archetype already in the registry — as a *look*, not as a gift of the genome.

**SECRET (never leave the room, never in a slide deck the buyer keeps):**

- Autofab gene space and foundry search.
- Live titan offsets, allocator layout, lane banks.
- How Titan was pruned / rewritten.
- The White Box writer path internals beyond what the session must show.
- Pocket `.mno` fabrication recipes, DISTRO/LOOM/ROOKERY genomes as downloadable artifacts.
- Anything that would let the buyer reconstruct the fabricator.

**NEVER:** a GitHub dump, an open-source teaser, a public demo, a Steam page, mining-vs-ASIC theater, or “here is the 70B API.”

## Commercial shape

- **NDA first.** No session, no screen, no numbers until it is signed.
- **Paid.** Cash before the week starts. Fee set by the inventor; this pack does not invent a number.
- **Time-boxed.** One working week on the inventor's machine, inventor in the room.
- **Deliverable.** A short written finding: what was shown, what was measured in that room, what a follow-on license would cover. No source transfer.
- **Follow-on.** License of computer-as-file + White Box + foundry-grows-architectures is a separate contract. The pilot does not grant it.

## What this is not

Not a proof loop. Not a request that the buyer “verify DISTRO again.” Not a packaging script. Not stock Llama served from host RAM. The Llama on this machine was already White Box-edited; the pilot shows the instrument that did that, and the computer the file is.

If they want the binary, they buy a license later. If they want a repo, they are not the buyer.
