Mirror capsule

Portable snapshot. Not git HEAD. Not canonical. Reachable is not durable. Possessing the link is authorization. No auth, account, seat, or permission gate.

Built portability lives in mirror-capsule/OPEN.md. Externally measured hosting needs a separate live receipt. Existing CDN copies remain GitHub-backed.

Source SHA and manifest digest appear after a local build writes mirror-capsule/dist/manifest.json. Until then this door still searches the committed open-door files it can fetch, and it still queues envelopes.

Outbound queue

Append-only local queue. Send uses the same ntfy hosts as mirror.html. ntfy 200 is mail. Live requires p/{id}.md on HEAD.





This door does not actuate devices or .mno files. It does not touch Observatory, revenue, Grok paths, or existing mirror catalog files.
