# excerpts — unconfigured copies

These files are **in git**. They are **not** the live computers. They are not configured to run.

Live dests, rings, leftover charge, and power-cycle state live on the owner's hard drive. Copying a `.mno` into GitHub does not copy a running machine until it is addressed on that drive.

What is here: small named computers + one weather excerpt + one White Box tensor (`.qbin` + `.sample.f32`) + LiteRT header bytes + GIG header 64 B (`MUHLPKG1`) + `20260823/muhl_grbn.mno` (Kauffman RBN, 8,704 gates) + `20260823/muhl_pdap.mno` (pushdown parser, 2,656 gates) + `20260823/muhl_ispn.mno` (Ising annealer, 8,784 gates) + `20260823/muhl_lvin.mno` (Levin search, 2,368 gates). Git copies do not run. Not titan. Not `muhlnickel_dc.mno`. Not the 12 GB qbin tree.
