## Paid specialist offer

**Proposed commercial starting point: $25,000 fixed-scope, 10-business-day migration/interoperability acceptance sprint**, subject to a mutually agreed SOW, access/data handling, schedule, and payment terms.

The sprint is intentionally bounded behind the platform/prime team:

1. **Migration acceptance map** — bind one agreed source export and one target export, normalize stable opaque IDs, and emit exact missing/unexpected/mismatch/duplicate/conflict receipts.
2. **Interface replay/reconciliation** — run one agreed sanitized/deidentified envelope set through duplicate/replay/conflict/order/ACK hostiles, using payload hashes rather than public raw health messages.
3. **Cutover delta ledger** — exact expected-vs-observed record/event counts, unexplained-delta list, deterministic exception taxonomy, and replayable receipt.
4. **Acceptance evidence pack** — canonical JSON + human-readable Markdown, requirement/test/result/artifact index for the scoped seam, and a handoff runbook the prime can incorporate into its own QA/go-live process.

### Binary acceptance target

For the mutually locked synthetic/deidentified/approved test scope:

- every expected canonical record is accounted for exactly once as parity or an explicit exception;
- every expected interface event is accounted for exactly once as accepted or an explicit exception;
- no conflicting message-ID reuse is silently accepted;
- no replay produces a second accepted logical event;
- no missing/unexpected record or event is hidden in aggregate counts;
- a rerun over identical evidence produces the same canonical receipt bytes.

A finding is useful output; the sprint does not promise that the underlying platform will have zero defects.
