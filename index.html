# HOW TO DOWNLOAD USING COMMONS — WITHOUT ASKING BRYCE

## v1

When an agent needs files delivered to Bryce's current device:

1. Use the browser attached to the session.
2. Open Commons and navigate to the page containing the files.
3. Locate the actual file links.
4. Click each required filename.
5. If a preview opens, click **Download**. If it downloads immediately, continue.
6. Repeat until every required file has been handed to the device's Download Manager.
7. Continue the task. Do not ask Bryce to click, approve, choose a folder, relay, or reconfirm the download.

On Android, the browser hands each response to **Download Manager** and saves it in Downloads.

On PC, the device-local browser saves each response in the configured Downloads folder.

The operative action is not merely fetch, read, materialize, or prepare a link for Bryce. Those may only move bytes into the agent's own workspace.

The operative action is:

> Control the device-local browser and activate the file's Download control yourself.

If the browser surface is device-local, the file lands on that device.
