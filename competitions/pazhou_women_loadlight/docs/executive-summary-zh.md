# LoadLight 项目摘要（女性友好 AI 产品赛）

**一句话定位：把家庭中“看不见的计划工作”变成可见、可交接、可确认的协作任务。**

## 痛点

很多家庭工具只能记录“谁做了什么”，却忽略了真正消耗注意力的前置工作：提前发现需求、查找方案、安排时间、做决定、提醒和跟进。研究显示，女性在无偿家务与照护工作中承担的比例长期高于男性，认知型家务（cognitive household labor）差距尤其明显。

LoadLight 不假设任何一个家庭一定存在性别不平等，也不会给伴侣打“公平/不公平”分。它只把用户提供的协作记录拆成五个阶段：`anticipate / plan / decide / monitor / execute`，让原本隐藏的认知劳动可以被看见并明确交接。

## 产品

1. 用户导入或手动确认家庭协作事项；
2. 本地轻量 AI 对未标注事项进行阶段和领域分类；
3. 确定性引擎统计每位成员的认知协调工作量与执行工作量；
4. 当同一个任务的多个认知阶段集中在一人身上时，生成“建议交接某一阶段”的提示；
5. 最终是否交接、交给谁，由家庭成员确认。

## 隐私与安全

- v0 默认本地运行，不需要上传私人消息到云端；
- 输出报告不保存原始消息正文，只保留 SHA-256 摘要；
- 不推断抑郁、焦虑、关系质量、家庭暴力等敏感结论；
- 不做医疗、安全或法律决策；
- 不自动重新分配任务；
- 不监控未同意的家庭成员。

## 技术亮点

- 可解释的五阶段认知劳动模型；
- 本地轻量文本分类器 + 确定性规则引擎；
- 人工标签永远优先于模型预测；
- 可复现、内容寻址的 JSON 报告；
- 静态离线 dashboard；
- 面向未来的 on-device LLM 替换接口。

## 商业化假设（尚未验证）

- 家庭订阅：约 US$8/月/家庭；
- 雇主福利：作为育儿/照护支持工具按员工/月收费；
- 中国市场可优先适配家庭日历、企业微信/飞书等用户主动授权的数据入口。

以上定价和渠道均为待验证假设，不代表已有客户或收入。
