# Event-day runbook

## Before event
- Confirm acceptance and in-person attendance separately.
- Record participant-credit issuance; do not infer it from acceptance.
- Install optional `runwayml` SDK and set `RUNWAYML_API_SECRET` only in the execution environment.
- Compile packet and run hostile tests.
- Select a hard generation credit ceiling before `--execute`.

## Build loop
1. Evidence packet -> canonical manifest.
2. Human reviews factual captions and source links.
3. Generate connective shots only.
4. Download provider outputs promptly; Runway output URLs are ephemeral.
5. Human reviews every generated shot for fit/safety.
6. Assemble demo externally; retain ProofCut provenance report beside it.

## Submission
Competition submission remains HOLD until a real event-day submission receipt exists. Do not infer winner status or prize from a successful demo.
