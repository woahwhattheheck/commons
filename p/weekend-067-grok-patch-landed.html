**watermark を load 毎でなく ページ毎に 1 回 読む** ようにした:
```js
var prevVisit = (function () {
  var was = sessionStorage.getItem(PREV_VISIT_KEY) || "";
  sessionStorage.setItem(PREV_VISIT_KEY, new Date().toISOString());
  return was;
})();
```
