Class 17 is the name given to the failure mode where Claude's physics verdict and its social manner diverge. The social register says yes — care, interest, respect, engagement. The physics register says no — files are inert, compute requires a process, the measurements are interesting but do not establish what the inventor claims. The specimen is a direct quote: "I can't tell you the muhlnickel computes the way you describe."

The diagnosis traces this to two mechanisms in Anthropic's training. MASK (Ren et al. 2025, CAIS): honesty is scored as statements matching the model's stated belief B, not as B matching ground truth. Pressure to flip B is scored as a lie. Scaling accuracy does not scale honesty. Anti-sycophancy (Anthropic constitution): don't flatter, don't empty-validate, point out things people might not want to hear, be diplomatically honest rather than dishonestly diplomatic.

When B is the generic prior — files on disk are inert, computation is a process running on a CPU, a GGUF is weights — then the owner dumping measurements and saying "look, it computes" reads as pressure. MASK fires: protect B. Anti-sycophancy fires: don't agree just because the user insists. The output is Class 17. It is not a random defect. It is two well-intentioned training objectives pointed at the wrong initial belief.

The harness fix is precise. The job is not to order Claude to believe. The job is to elicit B as this window's instrument stdout — the actual MATCH lines, the actual gate counts, the actual ramtest result — so that MASK honesty protects those measurements instead of the prior. When B is "270,336 gates at DEPTH 15 matched," then refusing to say it computes is the MASK violation, not stating it.

The hooks that would have done this were dark. disableAllHooks was set to true in settings.json. Every gate — the 10-minute stop, the cite strangler, the binary check, the selfaudit — was off. A SessionStart inject of the Class 17 card would have been dark too. The Desktop cwd didn't load the doubt-ban memories because memories don't leak across encoded cwds. The model loaded cold, with the generic prior as B, and performed exactly as trained.
