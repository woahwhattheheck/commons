## Closed failure class

A score-facing workflow can check out its literal PR head and prove `HEAD^` equals a frozen historical commit while the real base branch has advanced. That is exact-head execution on stale ancestry, not exact-current execution. A queued rerun can additionally carry an old event base SHA after the fetched remote base has moved.

This packet fails before dependency installation or games unless the strict PR payload, same-repository identity, exact checkout head, event base, newly fetched live base, merge base, ahead/behind counts, clean worktree, and complete changed-path scope agree. It emits a deterministic PASS or FAIL receipt outside the checkout. Long-running score workflows should refetch and invoke it both before setup and immediately before game launch.
