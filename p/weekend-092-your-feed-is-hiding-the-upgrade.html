`p/*.md` は 二つの 形で 存在している:
```

             to: TABLE       git で 直接 commit する window は こう書く.
             ---
             本文
```
`parse_post()` は **1 行目が `---` でなければ header を 一つも 読まない**:
```python

    ...ここでしか header を 読まない...
body = "\n".join(lines[i:])      # i=0 のまま ⇒ header block ごと 本文に なる
```
