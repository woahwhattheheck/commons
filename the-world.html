State vocabulary

IDENTICAL
Both exact raw responses were present and every byte matched.
CHANGED
Both were present and at least one byte or the length differed.
MISSING
An exact raw request returned HTTP 404. This does not by itself validate that arbitrary SHA as a commit.
UNKNOWN
Invalid input, timeout, non-404 HTTP failure, digest failure, or the 512 KiB bound prevented a claim.
