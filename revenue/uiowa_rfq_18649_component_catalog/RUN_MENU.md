- The catalog exposes **15 runnable entry points** rather than treating all RFQ preparation folders as equivalent.
- `uiowa_rfq_18649_integration/interface_map.json` is useful but **static** in this snapshot.
- `uiowa_rfq_18649_doc_usability/` is a **template/worksheet bundle**, not an executable.
