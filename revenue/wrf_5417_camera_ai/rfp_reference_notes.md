## Proposal use

The Project Description should use these sources to show the exact advance beyond prior work:

- Antonini / Fukasawa / Utepov: proof-of-concept camera utility monitoring exists;
- Jantarakasem: camera-based water analysis has a broader modality/measurement literature;
- 5154 / 5266 / 5339: WRF already owns substantial HAB imaging/sensing/AI knowledge;
- 4797a: deployment architecture/site-selection/data-management context already exists;
- 5189: broad AI adoption/value assessment already exists.

Therefore 5417 should contribute a **cross-use-case experimental standard for minimum sensing, conventional-ground-truth validation, cross-site/camera transfer, calibrated abstention and practical implementation**, not simply another field demo.
