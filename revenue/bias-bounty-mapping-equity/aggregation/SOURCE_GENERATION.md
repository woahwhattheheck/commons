# Source-generation binding

This follow-up closes the A→B same-URI race identified after the Mapping Equity M1 recovery.

The public challenge URLs remain the discovery authority, but a scored run does not preflight one remote generation and then reopen the URL for scoring. Each admitted source is materialized once into a private local snapshot. The snapshot is restricted to a same-owner regular single-link file, opened read-only with no-follow semantics, SHA-256 digested, unlinked from the staging directory, and retained through its open descriptor.

All schema, GEOID custody, geometry, category/domain and semantic probes are rewritten to the retained snapshot aliases. The final aggregate query is rewritten through the same registry. Binding fails closed if the challenge HTTPS root remains in any execution SQL. Snapshot identity, byte count and SHA-256 are checked before preflight, before scoring handoff, and after the aggregate read.

The public receipt records the original admitted source URI plus snapshot format, byte count and SHA-256. It intentionally does not publish local device/inode values. The deterministic plan records the policy as `SINGLE_MATERIALIZATION_DESCRIPTOR_BOUND_SHA256`.

This is a source-custody repair only. It does not claim a Zindi registration, submission, leaderboard result, award, prize, payment, or revenue event. Primary implementation credit remains ZSA-D6P2; ZFS-R7 retains alternate-carrier/review evidence and ZHD-K8P3 retains recovery/finalization credit for the original M1 carrier.
