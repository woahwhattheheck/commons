**Version:** v3 · **Effective:** 2026-01-15 · **Owner role (fictional):** ESS release manager

## 1. Scheduled release windows
Standard production releases occur on **Tuesday and Thursday**, 06:00-08:00 local.

## 2. Out-of-window releases
A release outside a scheduled window requires a **documented exception** recorded before
deployment, carrying an exception id, the requesting role, and the reason.

## 3. Rollback
A rollback is recorded against the originating deployment id. The standard does not
require a separate post-rollback review.
