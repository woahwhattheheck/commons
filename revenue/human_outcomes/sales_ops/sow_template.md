## Scope (copy the matching catalog sentence)

- `ho-issue-to-pr`: one named issue on one named public repository; one pull request; CI green on the integrated SHA; issue closed by that PR.
- `ho-meeting-packet`: one named public meeting; one packet (HTML plus printable); agenda, one-page brief, source list; no login to read.
- `ho-security-questionnaire`: one named questionnaire; every answer cites a public path or UNMEASURED; no invented certification; returned as a filled copy.
- `ho-pixel-pack`: one sprite, one walk loop, one speak line wired to a public post id on the existing 8bit door or a linked public page.

## Acceptance (must match offers.json)

A SKU is accepted only when every catalog `acceptance` row for that
id is true on a named SHA or a named public URL. A payment reference
never proves delivery.

## Refund and change order

Working boundaries, not statutory rights.

- Unstarted work after written intake: founder refunds the authorized amount.
- Missed provider clock: founder refunds or withholds the unpaid half.
- Buyer-late inputs move the calendar by the same number of days.
- Written change order (new issue, new meeting, extra questionnaire, extra sprite) stops the clock until signed.
- Style or policy disagreement after acceptance is not a refund.

## Out of scope (every SKU)

Auth, login, seat, memory, permission, or safety gates. Titan write.
`commons.mno` smash. Invented certifications. Buyer fiction. A claimed
checkout that does not exist. White Box GGUF work unless a later
separately scoped SOW names `white-box-gguf-pilot-30d`.
