## Go / no-go rule

**Current posture: HOLD / QUALIFICATION-REQUIRED.** The 40% technical-vision component can be made strong, but the 25% firm-experience component is impossible to truthfully optimize without real prior work evidence. If credible previous dashboard work and contracting authority cannot be supplied, do **not** submit a fabricated prime response. A teaming/subcontract route should be considered only if allowed without violating the RFP communication restriction or existing prime ownership.
