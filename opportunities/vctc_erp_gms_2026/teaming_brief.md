# Paid teaming brief — internal

## Position

VCTC is buying an ERP + best-of-breed Grants Management capability and implementation, not a generic software prototype. TJLabs should join only under a qualified ERP/GMS prime or vendor that can truthfully carry product authority, public-sector references, implementation leadership, support, demo, insurance and physical submission.

## Proposed specialist workshare

A separately negotiated fixed workshare can cover:

- migration reconciliation from Sage 50 / retained source extracts into the selected target;
- active-balance/open-transaction, vendor, project and grant crosswalk validation;
- interface retry/idempotency/duplicate-effect/rollback evidence for named integrations;
- requirement→configuration→test→UAT traceability and exception/retest lineage;
- cutover evidence packet and audit-ready implementation binder;
- shortlist/demo evidence support if separately accepted.

## Acceptance criteria

- deterministic source/target population and value reconciliation with explicit exceptions;
- every transformation and exception bound to evidence refs and retained generation roots;
- repeatable interface replay cases with duplicate-effect and rollback hostiles;
- requirement/UAT matrix has no silent drops and no machine-minted buyer acceptance;
- handoff includes reproducible manifests, runbook and operator-readable packet.

## Exclusions

No ERP/GMS license resale, product representation, prime credentials, VCTC contact/submission/signature, production access before contract, accounting/legal conclusion, award/payment/revenue claim, or free buyer-specific implementation.

## Commercial state

`PROPOSED_NOT_ACCEPTED`. Price is intentionally unbound until the exact Appendix A/B response structure and a prime's responsibility split are known.
