# Paid specialist workshare — internal draft

This is a **buyer-neutral internal scope skeleton**, not an offer, proposal, partnership, accepted price, or authorization to contact anyone.

## Candidate TJLabs work packages

### 1. Deterministic portal acceptance harness
Inputs owned by prime/buyer:
- approved requirements and acceptance criteria;
- lawful non-production/synthetic test data;
- environment/API access explicitly provisioned for testing.

Deliverables:
- reproducible workflow acceptance cases;
- upload/file/data-validation hostiles;
- canonical evidence receipts binding input generation, rule generation, observed result and disposition;
- regression summary with exact failed requirement identifiers.

Acceptance:
- same input/rule generation reproduces the same receipt;
- malformed/stale/transplanted evidence fails closed;
- no production mutation or business approval authority.

### 2. Transition / migration verification
Deliverables:
- source-to-target record-count and digest reconciliation;
- field-level transformation checks;
- exception inventory and owner-review queue;
- deterministic cutover-readiness report.

Acceptance:
- every reported migrated cohort binds exact source/target generations;
- no “complete” state if unexplained reconciliation gaps remain.

### 3. Reporting and data-quality verification
Deliverables:
- rule-based data-quality tests;
- report-input lineage checks;
- reproducible dashboard/report fixture validation;
- bounded anomaly evidence for human review.

Acceptance:
- no fabricated savings, compliance, approval, or production result;
- all findings cite retained inputs and exact rule generation.

### 4. Accessibility / security acceptance automation
Only where prime/buyer permits and supplies governing criteria.

Deliverables may include:
- deterministic accessibility regression checks around agreed WCAG acceptance criteria;
- evidence packaging for human security/accessibility review;
- negative tests for unsafe data handling or unauthorized routes.

This scope does **not** claim to replace a VPAT, SOC report, penetration test, HIPAA legal determination, OIT approval, or third-party assessment.
