## Run the current fixture

```bash
python3 qualify.py fixtures/public_hold.json
```

Expected exit code is `3` and state is `HOLD_QUESTIONNAIRE_REQUIRED`. The output `evaluated_at` is generated by the evaluator at runtime; the manifest's historical `evaluated_at` is retained only as `caller_evaluated_at` metadata.

Historical byte/digest validation is explicitly separate:

```bash
python3 qualify.py fixtures/public_hold.json --historical-integrity-only
```

That can return `HISTORICAL_INTEGRITY_VERIFIED`, but also returns `commercial_readiness=false` and never authorizes buyer submission.

## Current-readiness authority chain

A future READY path requires all of the following:

1. exact questionnaire bytes whose SHA-256 matches the reviewed `sources.json` record;
2. a **questionnaire extraction authority** binding those bytes, exact source-ledger bytes, notice/Atamis identity, version/addenda completeness, and the complete required-gate universe for every route;
3. the questionnaire-authority packet's exact SHA-256 deliberately retained in `TRUSTED_QUESTIONNAIRE_AUTHORITY_SHA256` by a reviewed source change;
4. a separately retained **capability evidence authority** binding claim-specific evidence IDs to artifact SHA-256, evidence type, capability and permitted route, plus a current validity window;
5. the evidence-authority packet's exact SHA-256 deliberately retained in `TRUSTED_EVIDENCE_AUTHORITY_SHA256`;
6. for teaming routes, a separately retained **partner-prime authority** bound to the exact opportunity, selected route, questionnaire authority, evidence generation and validity window, with its SHA-256 retained in `TRUSTED_PARTNER_AUTHORITY_SHA256`;
7. verifier-owned current time before the buyer deadline and within source/evidence/partner freshness windows;
8. every questionnaire-derived required gate proven by a matching retained evidence identity.

A manifest's `partner_prime_confirmed=true`, arbitrary evidence-reference strings, or caller-selected evaluation time have no current-readiness authority.
