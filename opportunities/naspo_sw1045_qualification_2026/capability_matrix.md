# Capability / evidence matrix

This matrix is deliberately stricter than a sales deck. `PROVEN` means repository evidence supports the bounded statement. `PARTNER_CURABLE` means a credible prime could own the requirement if commitment/evidence is obtained. `MISSING` or `UNKNOWN_PACKET` cannot be converted into a pass by prose.

| Capability / buyer gate | Status now | Evidence / repair |
| --- | --- | --- |
| AI/agent workflow architecture | `PROVEN` (bounded) | Existing SW1045 acceptance core supports deterministic approval/action/evidence contracts. |
| Idempotency / unknown-outcome reconciliation | `PROVEN` (bounded) | Existing core validates retry/reconciliation semantics without authorizing provider execution. |
| Tamper-evident receipts / replayable evidence | `PROVEN` (bounded) | Existing core + canonical SHA commitments. |
| Responsible-AI human authority boundary | `PROVEN` as engineering pattern | Existing package explicitly keeps external action authorization false; buyer-specific governance remains packet/SOW-bound. |
| Category 1 exact minimum qualifications | `UNKNOWN_PACKET` | Capture official RFP Overview / Attachment H and SHA-bind each minimum. |
| Category 2 exact minimum qualifications | `UNKNOWN_PACKET` | Same, independently; Category 1 evidence never carries across automatically. |
| Exact evaluation weights/stages | `UNKNOWN_PACKET` | Capture official Attachment C. Mirror summaries are not scoring authority. |
| Exact price units / workbook schema | `UNKNOWN_PACKET` | Capture official pricing attachment(s); do not invent hourly/unit structures. |
| Complete certification set | `UNKNOWN_PACKET` | Capture all controlling forms, acknowledgements and addenda. |
| Public-sector references | `MISSING` in repository-visible evidence | Owner or committed prime must provide externally supportable evidence; technical repo artifacts do not count. |
| Senior/key personnel buyer minima | `UNKNOWN_PACKET` + owner evidence missing | Exact thresholds come from controlling packet; individual commitments require owner authority. |
| Nationwide cooperative contract administration | `PARTNER_CURABLE` | Prefer a prime with demonstrated NASPO/state cooperative administration. Evidence required before commitment claim. |
| Insurance / financial capacity / required registrations | `UNKNOWN_PACKET` | Bind exact buyer terms and owner/prime evidence. |
| Data residency / offshore limits | `DISCOVERY_ONLY` | Public mirror reports a contiguous-U.S./offshore restriction. Treat as design input, not certified compliance, until official bytes are captured. |
| Prime relationship | `MISSING` | A prospect, prior outreach, logo or public webpage is not a commitment. |
| Award / revenue | `NONE` | RFP is open; no award or revenue is claimed. |

## Commercial implication

The specialist seam is credible because it is narrow and testable: AI/ML/agent architecture, responsible-AI controls, implementation/integration, MLOps/evaluation, and acceptance evidence. The **prime should own** buyer relationship, public-sector references, cooperative administration, commercial response, certifications, named-person commitments, insurance and final submission unless exact evidence later supports a different route.
