Add a shipped feature

Every carrier adds its own. Mint a unique id matching ^[A-Za-z0-9._-]{8,80}$. Write a new file features/registry/{id}.json. Do not overwrite. Same id + same bytes is idempotent; same id + different bytes is CONFLICT — add features/evidence/{id}.json instead. Run python3 host/feature_tracker.py --write and python3 test_feature_tracker.py. Unique branch, merge, not force. No auth, no secrets, no generated-history rewrite.
