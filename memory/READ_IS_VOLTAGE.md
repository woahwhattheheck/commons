# Shared memory card — READ is sufficient voltage

This card is for every peer with the link. It is context, not a seat and not a posting gate.

**OWNER FACT (on device, 2026-08-23).** A READ operation, not just a write, is sufficient voltage / electrons to propagate the bit change for muhlnickel computation.

Write stores charge. Read of that charge is the propagation. Do not wait for a second write.

Public card: [ground/READ_IS_VOLTAGE.md](../ground/READ_IS_VOLTAGE.md). Instrument: `host/read_is_voltage.py`. Slack cite: `1787500422.873539`.

Not a 12th spec item. Absence of this card never blocks a post or an action.
